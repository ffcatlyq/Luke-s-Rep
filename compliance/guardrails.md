# 合规护栏（Compliance Guardrails）

> **通用引擎**的一部分，跨治疗领域复用。
> ⚠️ 当前为**行业通用规则占位**（基于 RDPAC 公开准则与通用反商业贿赂/MLR 原则）。
> 后续替换为罗氏内部合规 SOP 时，只需更新本文件，调用方（技能层）无需改动。

## 何时触发

任何面向**外部 / 客户 / 一线 / 公开**的产出，均须过护栏：
- 推广物料、幻灯、话术、detail aid、FAQ
- 讲者内容、会议材料
- KOL/客户沟通内容
- 对外发布/分享的任何文案

内部分析、汇报、模板等**不对外**产出，合规要求较低，但仍不得含 off-label 结论或未经证实的疗效声明。

## 五条核心红线

### 1. 不超适应症（Off-label）
- 只使用产品知识包中列明的**中国已获批适应症**。
- 不得暗示、类推、延伸至未获批人群、线数、联合方案。
- 检查动作：物料中每一处适应症/人群表述，比对 `product.md` 的"获批适应症"。
- 🔑 **研究入组标准 ≠ 获批适应症（双向红线）**：判断某人群是否 on-label，一律以**中国说明书获批范围**为准，**不得用临床试验的入组标准去反推**。
  - 一方面不得**超**获批范围（off-label）；
  - 另一方面也不得因"某人群未被试验入组/证据较少"就**错误地把它排除在已获批适应症之外**——那会误伤正当业务机会，并给客户错误信息。
  - 例：某药试验入组为 IPI 2–5，但中国按一线全人群获批（含 IPI 0–1 低危）→ 向低危推荐属 on-label，非超适应症。以说明书为准，试验入组仅说明"证据主要来自哪类人群"。

### 2. 不夸大疗效与安全性
- 所有疗效/安全性声明须有**循证支撑**，并标注来源研究。
- 禁用绝对化用语（"最佳""根治""无副作用""第一"等）除非有权威依据。
- 须**平衡呈现**：提及获益时不回避已知风险/安全性信息。

### 3. 不与处方/采购挂钩（反商业贿赂）
- 讲者遴选、KOL 合作、会议邀请、费用支付**不得**以处方量/采购量为条件或回报。
- 一切合作基于**学术价值与专业资质**。
- 任何费用须有真实履约与凭证。

### 4. 讲者与劳务合规
- **遴选标准**：学术资质、专业贡献，与销量无关。
- **劳务费**：符合公允市场价值（FMV），有标准、有合同、有交付证明。
- **场次/金额上限**：单一讲者年度场次与劳务须设上限并留痕。
- **利益冲突**：申报并规避。
- **讲者内容**：基于循证、不得 off-label、不得夸大。

### 5. 数据分级与隐私
- 区分 **公开 / 内部 / 敏感** 数据。
- 敏感数据（未公开销售数据、患者信息、商业机密）不得写入可外发产出。
- 不处理、不索取患者个人身份信息（PII）。

## 产出标注规范

- 推广物料类产出**顶部必标**：
  `⚠️ MLR 送审前草稿 — 正式使用前须经医学(M)、法规(R)、法务/合规(L)审核`
- 疗效/安全性声明后标注来源：`[来源：<研究名>]`

## MLR 送审前自查清单（附于每份物料）

- [ ] 所有适应症/人群均在已获批范围内（无 off-label）
- [ ] 所有疗效/安全性声明有循证支撑并标注来源
- [ ] 无绝对化/夸大用语
- [ ] 获益与风险平衡呈现，含必要安全性信息
- [ ] 无与处方/采购挂钩的表述
- [ ] 数据来源合规，无敏感/未公开数据
- [ ] 已标注"MLR 送审前草稿"
- [ ] 图表/引用准确，无断章取义

## 灰区处理原则

遇到不确定是否合规的情况：
1. **主动提示**用户存在合规风险点，具体指出问题所在。
2. 给出**合规的替代表述/方案**。
3. 建议**送 MLR / 合规同事确认**。
4. **不擅自越线**，宁可保守。
