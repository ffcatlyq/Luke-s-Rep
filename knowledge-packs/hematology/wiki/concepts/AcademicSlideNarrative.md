# 学术幻灯叙事 — 科室会/专家会的结构方法论

> 通用幻灯叙事方法论，蒸馏自学术幻灯（推广/专家/医学/患教）的**结构层**（见 [[academic-slides]]，非原文）。用于组织科室会、专家会、患教材料的逻辑线。与工具技能 `slidev-authoring` / `pptx-authoring` 配合——本页管"讲什么顺序"，工具技能管"怎么做出来"。

学术幻灯不是卖点堆砌，是**一条逻辑线**：从疾病未满足需求走到产品价值，最后落到临床决策。

## 通用叙事结构

| 段 | 内容 | 目的 |
|---|---|---|
| 1 **疾病与未满足需求** | 流行病学、现有标准局限 | 建立"为什么需要新方案" |
| 2 **机制 MoA** | 产品作用机制 | 建立科学合理性（回产品卡） |
| 3 **核心循证** | 关键研究主终点 + 获益人群 | 用数据支撑主张 |
| 4 **定位与患者选择** | 目标患者/治疗线 | 落到"给谁用" |
| 5 **安全性与管理** | 分级数据 + 管理方案 | 平衡呈现（见 [[CRSCommunication]]） |
| 6 **临床决策小结** | 一句话带走 | 呼应信息屋核心（[[MessageHouse]]） |

## 分受众调整

| 受众 | 侧重 |
|---|---|
| **科室会（推广）** | 循证 + 患者选择，实操导向 |
| **专家会** | 深度循证、亚组、机制探讨 |
| **医学幻灯** | 严格循证、平衡、学术中立 |
| **患教** | 通俗、疾病认知 + 治疗信心，不涉处方决策语言 |

## 合规红线

- 幻灯循证**须标来源**（说明书版本/指南年份），不得超适应症。
- 患教材料**不得含引导处方的语言**，不夸大疗效。
- 所有对外幻灯标 `⚠️ MLR 送审前草稿`。
