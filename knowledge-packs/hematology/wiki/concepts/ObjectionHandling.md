# 异议应对 Objection Handling — 四步法

> 通用沟通方法论，蒸馏自区域 roleplay 话术的**结构层**（非原文，见 [[roleplay-talk-tracks]]）。用于医生提出疑虑时，以循证、合规、不贬损的方式回应。产品实例见各产品卡「常见异议与应对」段。

医生的异议不是障碍，是切入点。核心是**不辩驳、用循证收束**。

## 四步法

| 步 | 动作 | 要点 |
|---|---|---|
| 1 **识别 Identify** | 听清异议的真实类型（疗效？安全性？经济性？流程？） | 别急着答，先分类 |
| 2 **共情 Acknowledge** | 承认关切的合理性 | "您关注 XX 是对的" —— 不否定医生 |
| 3 **循证 Evidence** | 用说明书/指南/研究数据回应 | 数字标来源；只用已获批适应症数据 |
| 4 **收束 Close** | 回到患者获益，给出可执行结论 | 落到"哪类患者、怎么用" |

## 常见异议类型（血液/淋巴瘤场景）

| 类型 | 应对锚点 |
|---|---|
| **疗效增量是否值得** | 引关键研究主终点 + 获益人群（回产品卡核心循证） |
| **安全性顾虑**（如 ADC 神经病变、双抗 CRS） | 平衡呈现分级数据 + 说明书管理方案（见 [[CRSCommunication]]） |
| **经济性 / 生物类似药** | 客观陈述原研循证深度，**严禁贬损竞品** |
| **与竞品/CAR-T 如何选** | 回归适应症/线数/患者具体情况，基于公开数据 |

## 合规红线

- 只用**已获批适应症**的循证；不做超适应症延伸或跨线数暗示。
- **不贬损竞品**——比较须基于头对头或公开数据，客观陈述。
- 安全性异议必须**平衡呈现**，不得只讲疗效回避风险。
- 承载异议应对的物料/话术标 `⚠️ MLR 送审前草稿`。
