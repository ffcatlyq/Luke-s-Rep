# 组织结构 —— 血液 Customer Engagement 部门

> CE 部门的团队构成、汇报线与罗氏特色术语。智能体据此识别用户人群、对准汇报对象。
> ⚠️ 部门完整组织图与各角色详细职责为**后续待补充**，本文为当前已确认信息。

## 三条线概览

血液 CE 部门由三条线构成，共同向 Franchise Head（FH）汇聚：

```
                    Franchise Head（FH）
                   /                    \
          MM（中央市场）            RCL（生态群长官）
              |                    /        |
           PM（IC）            PSL        REL（部分区域才有）
                                |          |
                              PSM         LEL（圈长）
                                          （无 REL 区域，LEL 直接 → RCL）
```

**关键：RCL 与 MM 平级，均向 FH 汇报。** RCL 是区域市场线（PSL）与销售管理线（REL/LEL）的共同汇聚点。

## 三条汇报线明细

### 中央市场线（Central Marketing）
```
PM（产品经理，IC）
  └→ MM（Market Manager，市场经理）
       └→ Franchise Head（FH）
```

### 区域市场线（PST = Patient Solution Team，罗氏特色）
```
PSM（Patient Solution Manager，一线区域市场经理）
  └→ PSL（Patient Solution Lead，PST 长官）
       └→ RCL（生态群长官）
```

### 销售管理线（LEL → RCL 有两条路径）
```
圈长 LEL（Local Ecosystem Lead，地区经理）
  ├→【设 REL 的区域】→ REL（Regional Ecosystem Lead）→ RCL
  └→【未设 REL 的区域】→ 直接向 RCL 汇报
```

## 术语表

| 缩写 | 全称 | 中文 | 层级 |
|---|---|---|---|
| PM | Product Manager | 中央市场产品经理 | 中央市场，IC |
| MM | Market Manager | 市场经理 | 中央市场，PM 上级 |
| PST | Patient Solution Team | 患者解决方案团队 | 区域市场团队 |
| PSM | Patient Solution Manager | 一线区域市场经理 | 区域市场，IC/一线 |
| PSL | Patient Solution Lead | PST 长官 | 区域市场，PSM 上级 |
| LEL | Local Ecosystem Lead | 圈长（地区经理） | 销售管理，一线管理层 |
| REL | Regional Ecosystem Lead | 区域生态群长官 | 销售管理（**仅部分区域设置**） |
| RCL | Regional Cluster Lead | 生态群长官 | PSL / REL / LEL 汇聚上级，**与 MM 平级** |
| FH | Franchise Head | 事业部负责人 | MM 与 RCL 共同上级 |

> ⚠️ 英文全称部分为推断（PST/PSM/PSL/LEL/REL/RCL），**待核实**。

## 汇报路径要点（智能体识别用户时用）

- **RCL 与 MM 平级**，同向 FH 汇报。
- **LEL → RCL 有两条路径**：设 REL 的区域走 LEL → REL → RCL；未设 REL 的区域 LEL 直接 → RCL。识别销售管理线用户时，需先确认其区域是否设 REL。
- 主要跨部门伙伴：Medical（医学）/ Market Access（市场准入）/ RWE / Regulatory（注册）/ Compliance（合规）。
