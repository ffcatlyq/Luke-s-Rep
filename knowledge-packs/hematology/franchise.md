# 产品组合逻辑 —— 血液 Hematology

> 支持"单品视角"与"组合视角"双重分析。这是本知识包的核心洞察。

## 组合全景

罗氏血液组合覆盖**淋巴瘤全周期 + 血友病独立赛道**：

```
淋巴瘤（CD20 阳性 B 细胞肿瘤为核心）
├─ CD20 单抗基石
│   ├─ 美罗华 rituximab       抗 CD20 一代，成熟基石（面临生物类似药）
│   └─ 佳罗华 obinutuzumab    抗 CD20 糖基化改造，franchise 升级
├─ ADC（复发难治/联合增效）
│   └─ 优罗华 polatuzumab v.  抗 CD79b ADC，切入 DLBCL
└─ CD20×CD3 双抗（复发难治新兴）
    ├─ 高罗华 glofitamab       R/R DLBCL
    └─ 皓罗华 mosunetuzumab    R/R FL

血友病 A（独立赛道）
└─ 舒友立乐 emicizumab        FVIIIa 拟似双抗，长期预防
```

## 组合协同关系

| 关系类型 | 涉及产品 | 协同逻辑 |
|---|---|---|
| **CD20 franchise 全周期** | 美罗华 → 佳罗华 | 从一代基石到糖基化升级，覆盖不同瘤种与治疗线，franchise 生命周期管理 |
| **淋巴瘤全线布局** | 美罗华/佳罗华（一线基石）→ 优罗华（ADC）→ 高罗华/皓罗华（双抗，R/R） | 从一线到复发难治的接力，覆盖患者全病程 |
| **双抗组合分瘤种** | 高罗华（DLBCL）+ 皓罗华（FL） | 同为 CD20×CD3 双抗，按瘤种分工，共享双抗学术教育与市场培育 |
| **机制协同（潜力）** | 抗 CD20 + ADC / 双抗 | 联合方案的科学基础（须以已获批方案为准，探索性方案不得推广） |
| **独立赛道** | 舒友立乐 | 血友病，独立打法，与淋巴瘤组合无直接协同 |

## 单品在组合中的角色

| 产品 | 组合角色 | 定位一句话 |
|---|---|---|
| 美罗华 rituximab | 成熟基石 / 现金牛 | CD20 治疗奠基者，守住基本盘应对生物类似药 |
| 佳罗华 obinutuzumab | franchise 升级 | 新一代 CD20，延续并升级 CD20 领导地位 |
| 优罗华 polatuzumab v. | 增长引擎 | ADC 切入 DLBCL，提升一线与 R/R 价值 |
| 高罗华 glofitamab | 新兴增长 | R/R DLBCL 双抗，打开复发难治新格局 |
| 皓罗华 mosunetuzumab | 新兴增长 | R/R FL 双抗，惰性淋巴瘤新选择 |
| 舒友立乐 emicizumab | 独立增长 | 血友病 A 长期预防的变革性选择 |

## PM 视角的组合启示
- **淋巴瘤内**：可打"罗氏全病程解决方案"故事，但每个产品的推广须严守各自**已获批适应症**，不得跨产品暗示未获批联合。
- **双抗市场培育**：高罗华与皓罗华共享双抗品类教育（作用机制、CRS 管理等），可协同做学术，分瘤种落地。
- **CD20 防守**：美罗华面对生物类似药，重心转向循证差异化与佳罗华升级承接。
- **血友病**：独立资源与打法，与淋巴瘤团队协作但故事线分开。
