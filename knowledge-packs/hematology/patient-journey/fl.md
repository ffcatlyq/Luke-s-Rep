# 中国 FL 患者旅程（初治 + 复发）

> **这是什么**：滤泡性淋巴瘤（FL）在中国的**全病程患者旅程**——从初发症状到多次复发，每阶段的地点、科室、决策分支、评估标准、患者行为，**并带各节点的真实比例/DOT 数据**。
> **怎么用**：① 涉及 FL 患者流/治疗需求/预后转归的分析先读它；② 与五步法配套找**业务机会点**（映射方法见 `skills/hospital-business-analysis/references/patient-journey-mapping.md`）。
> **FL 与 DLBCL 的关键差异**：FL 是**惰性、不可治愈、需长期管理**的淋巴瘤——重心在"观察等待 vs 何时治疗""维持期依从性""反复复发的长期 PFS 管理"，与 DLBCL 的"治愈性冲刺"逻辑不同。

## ⚠️ 使用边界（务必先读）

- **机会点为草稿**：下方「⭐机会点」是**待验证线索**，非结论；落到客户前结合该院实况。
- **数据口径**：比例/DOT 数字来自来源材料（含个案师管理对比、部分标注"Ⅲ期临床研究"），属**内部调研/研究口径**，非说明书循证；引用于内部分析，**不作对外疗效声明**。
- **合规**：涉及产品严格限知识包已载**已获批适应症**——奥妥珠单抗（G）/ 利妥昔单抗（R）的 FL 线；不超适应症、不夸大，对外产出走 `compliance/guardrails.md` §5 + MLR。
- **循证以说明书为准**：对外疗效表述引产品卡来源，不用本文件的调研数字。

## 旅程总览（对应五步法漏斗）

```
初发症状 → 就医(Week0) → 确诊分期预后(Week4) → 治疗决策(观察等待 vs 治疗) →
初治方案(C1)→ 系统治疗 C2-C8 → 中期/EOT 评估 → 维持期(Week32-128) → 随访 →
〔复发〕→ 首次复发分层与方案 → 治疗/随访 → 二次及以上复发 → …长期管理
```

| 五步法漏斗 | FL 旅程阶段 |
|---|---|
| 步1 诊断率 | 初发症状 · 就医（非专业科室分流、异地就医）|
| 步2 导入率 | 确诊分期（病理+骨髓+分子）|
| 步3 轮转率 | 治疗决策（观察等待 vs 治疗）· 分期分层 |
| 步4 转化率 | 初治方案 C1-C8 · 复发线方案选择 |
| 步5 DOT | **维持期依从性**（FL 的重中之重）· 随访 |

## 一、初治线

### 阶段 1｜初发症状 · 就医（Week 0）〔步1 诊断率〕

| 维度 | 内容 |
|---|---|
| 流行病学 | 年新发 FL 占 B 细胞淋巴瘤 8%–12% |
| 初发症状 | 淋巴结肿大、持续发热、体重下降等 |
| 科室选择 | **非专业科室**（内科/外科/头颈外科）vs 专业科室（淋巴瘤科/血液科/肿瘤内科）|
| 患者决策阻碍 | 疾病认知不足、异地就医成本、就近就医（当地不具备诊疗能力）|
| **诊断数据（漏点量化）** | **84% 被怀疑其他疾病**；16% 被诊断为其他淋巴瘤亚型；**23% 患者无法及时确诊**（77% 可及时确诊）|
| ⭐机会点（草稿）| **84% 首诊被误判 + 23% 不能及时确诊 = 诊断率明确漏点。** 机会：非专业科室的 FL 识别教育、基层→专业中心转诊路径、异地就医的就近诊断支持。|

### 阶段 2｜确诊、分期与预后评估（Week 4）〔步2 导入率〕

| 维度 | 内容 |
|---|---|
| 地点 | 具备淋巴瘤诊疗能力中心（不具备则就近就医）|
| 基础评估 | 病史体检；血常规；生化（LDH、β2-微球蛋白、肝肾功能、尿酸）；乙肝筛查（避免化疗后再激活）|
| 影像 | 增强 CT（颈胸腹盆）；PET/CT（选择性，怀疑转化/高 SUV 提示高转化风险）|
| 病理 | 组织形态分级（1/2/3A/3B 级）；免疫组化（CD20+、CD10+、BCL6+、BCL2+、CD23-/+、CD3-、CD5-、cyclinD1-）；**分子检测 BCL2 重排**；骨髓活检（明确骨髓受累，影响分期）|
| 分期（Ann Arbor）| Ⅰ-Ⅱ 早期（20-30% Ⅰ/Ⅱ 期，10-15% 非局限 Ⅱ 期）；Ⅲ-Ⅳ 晚期（**70-80% 晚期不可治愈**）；标注有无大肿块（≥7cm，影响 CD20 方案）|
| 预后 | FLIPI 评分 |
| ⭐机会点（草稿）| 分级（3B 级近似侵袭性）、BCL2 重排、大肿块评估直接影响方案分层；**70-80% 确诊即晚期不可治愈** → 长期管理需求从确诊即开始。|

### 阶段 3｜治疗决策（观察等待 vs 治疗）〔步3 轮转率〕

FL 特有的关键岔路：

| 决策 | 比例 | 说明 |
|---|---|---|
| 立即治疗 | 40-50% | 出现治疗指征后进入治疗 |
| 观察等待（watch & wait）| 30% | 无治疗指征者定期随访 |
| 局限侵犯放疗 | 10-15%（Ⅰ/Ⅱ 期局限）| CD20±化疗+放疗 或放疗 |

| ⭐机会点（草稿）| **"观察等待"的 30% 是易流失/易断联人群**——无治疗但需定期监测，管理断点大（呼应智小伴数智随访）。何时从 W&W 转入治疗（治疗指征把握）是学术沟通点。|

### 阶段 4｜初治方案（Week 8）· C1〔步4 转化率〕

| 免疫化疗方案（CD20 + 化疗）| 分布 |
|---|---|
| **奥妥珠单抗 + 化疗（G-chemo）** | **62%** |
| **利妥昔单抗 + 化疗（R-chemo）** | 38% |
| 具体化疗骨架 | CD20+Benda / CD20+CHOP / CD20+CVP / CD20+Len |

| ⭐机会点（草稿）| G 一线占比 62% 已领先（G 一线 FL 已获批，GALLIUM 示 PFS 获益，见产品卡）；剩余 R-chemo 人群 + 大肿块/高危 FLIPI 是差异化沟通空间。方案选择受大肿块（≥7cm）影响。|

### 阶段 5｜系统治疗期 C2-C8 · 中期/EOT 评估（Week 8-32）〔步4→5〕

| 维度 | 内容 |
|---|---|
| 中期评估 | C3 或 C4；EOT 评估 |
| 评估标准 | Lugano 标准影像负荷评估（**须 PET-CT Deauville 评分**）；也有基于临床经验（增强CT+实验室综合判定）|
| 结果 | CR / PR / SD / PD |
| 生物标志物 | 疾病活动性、分子标志物、MRD 检测（临床研究相关）|
| ⭐机会点（草稿）| PET-CT/Deauville 规范化、MRD 检测渗透率是评估质量抓手；PD/SD 者进入复发/难治路径。|

### 阶段 6｜维持期治疗（Week 32-128）〔步5 DOT —— FL 的核心战场〕

**这是 FL 全旅程业务价值最高、也最易漏的一步。**

| 维度 | 内容 |
|---|---|
| 方案 | CD20 单药维持，每 2 月一次，维持 2 年 |
| 进入率 | 约 **78% 患者可进入维持期**（Ⅲ期临床研究口径）|
| **DOT 现状（关键）** | CD20 单药每2月一次、维持2年，**实际平均 DOT 约 2 支；个案师管理下达 8.7 支** |
| 观念漏点 | **不重视维持期治疗**、专家推荐观念差异、输注阻碍（床位不足、门诊输注未打通、异地成本）|
| ⭐机会点（草稿）| **维持期 DOT 巨大缺口 = FL 最大机会点：实际约2支 vs 规范应更高，个案师管理可拉到8.7支（提升数倍）。** 机会：①个案师/患者服务项目（直接抬 DOT）；②门诊输注路径打通（解输注阻碍这一结构问题）；③维持期价值的医生观念沟通。这是"结构+观念"双重漏点，须先辨清（见质询透镜）。|

### 阶段 6b｜患者服务（贯穿）

| 维度 | 内容 |
|---|---|
| 内容 | 定期提醒告知、个案师管理、生活质量关注 |
| 数据佐证 | 规范三针（1-8-15）治疗：无管理 54% → **个案师管理 86%**；单针仅用 46% |
| ⭐机会点（草稿）| 个案师管理对**初治规范给药**（54%→86%）和**维持 DOT**（2→8.7 支）都有数倍提升——患者服务体系是 FL 全程 DOT 的核心杠杆。|

## 二、复发线

### 阶段 7｜首次复发 · 患者分层〔步4 转化率·复发〕

| 分层维度 | 数据 |
|---|---|
| 复发时点 | **66-77% 为 2 年以上复发**；**20-30% POD24**（24 月内进展，预后不良）|
| 转化 | 3-4% 转化为侵袭性（如 DLBCL）→ 转 DLBCL 方案 |
| 优势患者画像 | **POD24、化疗不耐受、预后不良因素** |
| 市场量 | 市场调研预测年 5000 人次 |

| 治疗方案 | 分布 |
|---|---|
| CD20 base 方案 | 46% |
| CD20+苯达 / CD20+Len / CD20+化疗 | 25% / 20% / 23%（注：来源含初治交叉方案口径）|
| PI3K | 18% |
| 自体移植 | 14% |
| 临床试验 | 17% |
| BTKi | （暂无数据，新获批 GZ 方案）|

**治疗原则**：延长 PFS、尽可能降低治疗相关不良反应、改善生活质量。
**指南优先**：CD20 与化疗与初治采用**交叉方案**；2 年以上复发可沿用原 CD20；**R 转换 G，或维持 G**。

| ⭐机会点（草稿）| **POD24/化疗不耐受/预后不良 = 复发线高价值人群。** 按获批边界：R 的 R/R FL 适应症、G 的 FL 线（R→G 转换、2年以上复发沿用/转 G 是指南方向，线数以说明书为准）。T 细胞疗法机制优越性是新兴沟通点（CAR-T 等，以获批为准）。|

### 阶段 8｜二次及以上复发〔长期管理〕

| 治疗方案 | 分布 |
|---|---|
| CD20+Len | 20% |
| CD20+苯达 | 25% |
| CD20+化疗 | 23% |
| BTKi | 10% |
| PI3K | 7% |
| 自体移植 | 8% |
| 临床试验 | 6% |
| CAR-T | 5% |

| 特征 | 多为预后不良因素患者；自费价格因素影响方案可及性 |
| ⭐机会点（草稿）| 多次复发以延长 PFS、控毒、保生活质量为原则；可及性（自费/价格）是方案落地的现实约束；新机制（CAR-T/双抗）在此人群渗透。|

## 关键洞察（供机会点分析）

1. **诊断率漏点量化明确**：84% 首诊被误判、23% 不能及时确诊 —— 非专业科室识别 + 转诊路径是上游高杠杆。
2. **⭐维持期 DOT 是 FL 最大机会点**：实际约 2 支 vs 个案师管理 8.7 支，差数倍；"不重视维持 + 输注阻碍"是结构+观念双重漏点。
3. **患者服务是全程 DOT 杠杆**：初治规范给药 54%→86%、维持 DOT 2→8.7 支，都靠个案师管理拉动。
4. **观察等待的 30%**：无治疗但需长期监测，是易断联、易流失人群。
5. **POD24/化疗不耐受/预后不良**：复发线的高价值差异化人群。
6. **G 一线已占 62%**：一线格局领先，增量在剩余 R-chemo 转化 + 复发线 R→G 转换。

> **FL vs DLBCL 打法差异**：DLBCL 重"治愈性冲刺 + 复发线双抗/ADC"；FL 重"长期管理 —— 维持期 DOT + 患者服务 + 反复复发的 PFS 管理"。同一套五步法，漏点位置不同。
