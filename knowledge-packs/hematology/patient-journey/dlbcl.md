# 中国 DLBCL 患者旅程（初治 + 复发/难治）

> **这是什么**：弥漫大 B 细胞淋巴瘤（DLBCL）在中国的**全病程患者旅程**——从症状初现到终末期，每阶段的地点、科室、决策分支、评估标准、患者行为。
> **怎么用**：① 任何涉及 DLBCL 患者流/治疗需求/预后转归的分析先读它；② 与五步法（患者流漏斗）配套——把某家医院的实际流转对照"标准旅程"，快速定位偏差与**业务机会点**。映射方法见 `skills/hospital-business-analysis/references/patient-journey-mapping.md`。

## ⚠️ 使用边界（务必先读）

- **机会点为草稿**：下方「⭐机会点」列是**待验证的分析线索**，非结论。落到具体客户前需结合该院实况。
- **合规**：机会点凡涉及产品，严格限**知识包已载的已获批适应症**（Pola / Glofit / 利妥昔的 DLBCL 适应症；奥妥珠单抗仅 FL/CLL，**不涉 DLBCL**）。不超适应症、不夸大、不承诺；对外产出走 `compliance/guardrails.md` §5 + MLR。
- **循证以说明书为准**：涉及疗效数据时引产品卡的来源，不凭记忆。

## 旅程总览（对应五步法漏斗）

```
症状初现 → 首次就医 → 病理确诊 → 初治评估 → C1 用量 → C2-C4 中期评估
   → C5-C8 巩固/结疗 → 出院随访 →〔复发/难治〕→ 复发评估 → 复发疗效评估
   → 再复发 → 二次+复发评估 → 终末期决策
```

| 旅程阶段 | 对应五步法 |
|---|---|
| 症状初现 · 首次就医 | 步1 首诊鉴别（诊断率）|
| 病理确诊 | 步2 明确诊断（导入率）|
| 初治评估 · C1 用量 | 步3 收治均衡（轮转率）|
| C2-C8 治疗与评估 · 复发线方案 | 步4 治疗方案（转化率）|
| 各随访 · 结疗 · DOT | 步5 周期规范（DOT）|

## 一、初治线

### 阶段 1｜症状初现（0–3 月）· 首次就医（~1 月）〔步1 诊断率〕

| 维度 | 内容 |
|---|---|
| 地点/科室 | 家庭/社区 → 基层医院；**首诊高度分散**：普外/头颈外科、血液科、感染科、内科、消化科、神经科、皮肤科、骨科、呼吸科、胸外科、耳鼻喉科… |
| 关键症状 | 无痛性淋巴结肿大、反复低烧/盗汗、体重骤降（>10%）、结外症状（腹痛/鼻塞）、呼吸困难、头痛、皮肤溃疡 |
| 关键检查 | 问诊查体（症状+家族史、触诊淋巴结/肝脾）；实验室（血常规、血生化、炎症指标）；影像（B 超、CT、MRI、必要时 PET-CT）|
| **患者行为（漏点根因）** | 自行买消炎药/中药；"怕麻烦"拖延就医 → **延误就诊** |
| ⭐机会点（草稿）| **首诊分散 + 患者拖延 = 诊断率最大漏点。** 机会：多科室（非血液科）淋巴瘤识别教育、基层→三级转诊路径、无痛性淋巴结肿大的患者端疾病认知。→ 呼应五步法市一 case「病理-血液断链」。|

### 阶段 2｜DLBCL 病理确诊（金标准，1–4 周）〔步2 导入率〕

| 维度 | 内容 |
|---|---|
| 地点/科室 | 三级医院 · **病理科** |
| 要点 | 病理是确诊金标准；确诊后需导向血液/肿瘤科 |
| ⭐机会点（草稿）| 病理→血液科的**转诊闭环**是导入率关键；病理科淋巴瘤分型能力（GCB/ABC/DHL）影响后续分层。|

### 阶段 3｜初治患者治疗方案评估 · C1 用量调整〔步3 轮转率〕

评估维度（决定分层与可收治性）：

| 评估轴 | 分层 |
|---|---|
| 临床分期 | 早期(Ⅰ-Ⅱ) / 晚期(Ⅲ-Ⅳ) |
| 分子分型 | GCB / ABC(non-GCB) / 双打击·三打击(DHL/THL) / 双表达(DEL, MYC+BCL2+) |
| 预后指数 | IPI/aaIPI：低危 / 中危 / 高危 |
| 体能状态 | ECOG/KPS：良好 / 中度受损 / 差 |
| 特殊部位 | 原发纵膈 / 原发中枢 / 原发睾丸·乳腺 |

| ⭐机会点（草稿）| **分层即产品切入点地图。** 一线 Pola-R-CHP 为**全人群 on-label（不设 IPI 门槛，含 IPI 0-1 低危，医保覆盖）**——低危患者常被误判"不用强化方案"而漏（见产品卡「研究入组≠获批人群」）。老年/体弱、特殊部位患者的收治与方案选择是难点，也是差异化沟通点。|

### 阶段 4｜C2-C4 中期评估与用药调整〔步4 转化率〕

| 维度 | 内容 |
|---|---|
| 评估时间 | 高危：第 2 疗程后；低危：第 3-4 疗程后 |
| 评估内容 | 影像（核心）：PET-CT（金标准）/ 增强 CT（替代）；临床实验室：B 症状、LDH、ctDNA |
| 评估标准（Deauville）| CR(1-3分)→继续原方案；PR(4分)→继续+密切随访；SD(4-5分)/PD(5分)→**必须更换方案** |
| 影响 C2 调整因素 | 新发分子/高危因素、疾病进展 → 升级强化/加靶向；严重不良反应、体能变化 → 停药或换低毒方案 |
| ⭐机会点（草稿）| 中期评估的 PD/SD 是**换方案决策点**——复发线产品的前哨。ctDNA/PET-CT 规范化是评估质量抓手。|

### 阶段 5｜C5-C8 巩固治疗及结疗评估〔步4→5〕

| 维度 | 内容 |
|---|---|
| 地点 | 一线治疗医院、头部核心医院 |
| 结疗评估时间 | 所有治疗结束后 6-8 周 |
| 评估内容 | 影像：PET-CT（金标准）；实验室：LDH、β2-微球蛋白、ctDNA |
| 评估标准 | CR→维持原方案；PR/SD/PD→结合临床病理调整后续治疗 |
| ⭐机会点（草稿）| 结疗质量与规范评估影响长期结局判断；结疗未达 CR 者进入复发/难治管理，衔接下一线。|

### 阶段 6｜出院随访〔步5 DOT〕

| 维度 | 内容 |
|---|---|
| 地点 | 既往治疗医院、二级医院 |
| 随访时间 | 1-2 年每 3 月、3-5 年每半年、5 年后每年 |
| 随访内容 | 患者记录（体温/体重/淋巴结触诊）；医学检查（查体、LDH、血常规、影像 CT）|
| 发现异常 | 复发/难治；化疗不耐受（反复 3-4 级骨髓抑制、累积神经毒性）→ 减量；严重过敏/不可逆器官损伤/持续骨髓抑制 → **必须停药** |
| ⭐机会点（草稿）| 随访依从性 = DOT 保障；下沉二级医院随访存在管理断点（呼应"智小伴"数智随访场景）。|

## 二、复发/难治线

### 阶段 7｜首次复发/难治用药方案评估〔步4 转化率·复发〕

| 评估维度 | 分层 |
|---|---|
| 复发/难治类型 | 早期复发 / 晚期复发 / 难治（1L 未缓解或缓解后 6 月内复发）|
| 体能与年龄 | 年轻且体能良好 / 老年或体弱 |
| 分子·遗传 | GCB/ABC、DHL/THL、MYD88/CD79b 突变、TP53 突变 |
| 药物可及性 | 自体移植 / CAR-T / 双抗 |

**方案选择**：

| 移植条件 | 方案 |
|---|---|
| 符合移植 | (DHAP/ICE/GDP ± 抗CD20单抗) + 自体造血干细胞移植 |
| 不符合移植 | DHAP/ICE/GDP/DA-EPOCH ± 抗CD20单抗；**Glofit-GemOx**；**Pola-BR**；CAR-T；临床试验 |

| ⭐机会点（草稿）| **复发线是双抗/ADC 的核心战场。** 按获批边界：**Pola-BR** 用于 R/R DLBCL；**Glofit** 单药用于 ≥2 线经治 R/R DLBCL、Glofit-GemOx 用于**不适合 ASCT** 的 R/R DLBCL NOS（见产品卡，线数/人群以说明书为准）。**不符合移植 + 老年体弱 + TP53 突变**是差异化沟通的高价值人群。|

### 阶段 8｜首次复发疗效评估及方案调整

| 维度 | 内容 |
|---|---|
| 中期评估 | 2-4 周期后 |
| 结果→调整 | CR→维持原方案；PR→继续+密切随访；PD→优化原方案、增加联合 |

### 阶段 9｜首次复发随访及再次复发

| 维度 | 内容 |
|---|---|
| 随访时间 | 1-2 年每 3 月、3-5 年每半年（持续 10 年以上）|
| 随访内容 | 影像(PET-CT)、实验室、骨髓检查；**MRD 阳性或代谢活性升高即考虑干预** |

### 阶段 10｜二次及多次复发/难治方案评估

- 评估内容参考首次复发；
- 附加高危因素：大包块、中枢累及、≥2 次复发/难治；
- 经济维度：自身经济、惠民保、商保；
- 方案：符合移植→异基因造血干细胞移植；不符合移植→（参照首次复发的双抗/CAR-T/临床试验）。

### 阶段 11｜终末期决策

| 张力 | 走向 |
|---|---|
| 子女坚持"积极治疗" vs 患者希望"减少痛苦" | 继续尝试新方案 / 转入安宁病房（镇痛+心理支持）|

| ⭐机会点（草稿）| 终末期是**家庭决策**而非纯医学决策；此阶段以患者获益与人文关怀为先，产品沟通须审慎、合规。|

## 关键洞察（供机会点分析）

1. **诊断率漏点在最前端**：首诊分散到 10+ 科室 + 患者拖延，是全旅程最大的量损失口——多科室识别教育与转诊路径是上游高杠杆动作。
2. **分层 = 产品地图**：初治的 IPI/分子分型/体能/特殊部位、复发的移植条件/突变/可及性，共同决定每个患者的方案分支与产品切入点。
3. **两个"必须换方案"决策点**：中期评估 PD/SD、结疗未达 CR——复发线产品的前哨。
4. **低危 ≠ 不需强化**：一线 Pola-R-CHP 全人群 on-label，IPI 0-1 常被漏（常见误区，见产品卡）。
5. **不符合移植的老年/TP53 人群**：复发线双抗/ADC 的差异化高价值人群。
