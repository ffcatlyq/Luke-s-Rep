# 岗位对齐设计 — 罗氏中国 Customer Engagement 部门

> 基于三类人群的岗位要求（JD）细化平台设计：校准角色权重、明确产出物、界定合规敏感度。
> 配合 `architecture.md` 阅读。智能体按 `profile.yaml` 的 `role` 取对应画像。

## 0. 三类人群总览

CE 部门智能体服务三类人群，每类的岗位性质、汇报线、核心动词与合规敏感点不同。技能内按人群分流，取对应画像。

| 人群（role） | 岗位性质 | 汇报线 | 核心动词 | 高合规敏感职责 |
|---|---|---|---|---|
| **中央市场**（central-marketing） | IC，执行 + 战术落地 | PM → MM → FH | implement / execute / drive / collaborate | 讲者管理、推广物料 |
| **区域市场**（pst） | 一线区域执行 + 团队（PSL） | PSM → PSL → RCL | localize / execute / align / engage | 区域活动、客户互动 |
| **销售管理**（sales-mgmt） | People manager（圈长及以上） | LEL →（REL）→ RCL | coach / review / manage / drive | 团队激励（不与销量硬挂钩）、辖区资源 |

---

## 1. 中央市场 PM（central-marketing）

### 岗位画像
- **性质**：个人贡献者（IC），执行导向 + 战术落地，非纯策略岗
- **策略角色**：**参与**品牌策略共创（与 brand team / cross-functional），而非独立制定
- **核心动词**：implement / execute / drive / collaborate / communicate / develop（system）
- **硬技能**：项目管理、跨部门沟通、**中英双语**演示与写作、results-driven
- **高合规敏感职责**：讲者管理体系（Speaker Management）

### 角色权重
| 角色 | 权重 | 具体含义 |
|---|---|---|
| **助理**（执行） | 高 | 战术物料起草、项目跟踪、会议管理、双语汇报、讲者流程 |
| **参谋**（决策） | 中 | 打磨战术质量、竞品/客户洞察、策略共创输入，**不替其定顶层策略** |
| **赋能**（沉淀） | 中 | 最佳实践分享、讲者管理体系、模板/Playbook |

### 职责 → 产出物
| JD 职责 | 产出物 | 合规护栏 |
|---|---|---|
| 落地策略+战术 | Cycle plan 草稿、战术分解表、执行时间线 | 否 |
| KOL/客户维护 | 专家画像、分层清单、互动纪要、覆盖 gap 报告 | 部分 |
| 品牌策略共创 | 策略共创输入包、市场/竞品洞察简报 | 否 |
| **讲者管理体系** | 讲者库、遴选标准、场次分配、合规自查、运营看板 | **是（强）** |
| 跨部门沟通 | 跨部门 brief、对齐邮件、**中英双语汇报稿** | 否 |

### KPI（推断）
执行质量（按时按质交付）、KOL/讲者运营（覆盖率、合规运营）、市场表现（销量/份额）、协作有效性。

## 2. 区域市场 PST（pst）

> PST = Patient Solution Team（罗氏特色）。PSM = 一线区域市场经理；PSL = PST 长官。

### 岗位画像
- **性质**：区域市场执行（PSM 为 IC/一线，PSL 兼团队管理）
- **策略角色**：把中央品牌策略**本地化落地**，收集区域反馈上传；不制定顶层策略
- **核心动词**：localize（本地化）/ execute / align（中央-区域对齐）/ engage（客户互动）
- **硬技能**：区域计划、活动执行、跨层级沟通、客户覆盖运营
- **高合规敏感职责**：区域学术活动、客户互动（面对面 + 数字渠道）

### 角色权重
| 角色 | 权重 | 具体含义 |
|---|---|---|
| **助理**（执行） | 高 | 区域计划落地、区域活动执行清单、中央-区域对齐 brief、客户覆盖表 |
| **参谋**（决策） | 中 | 区域竞争格局、客户分层与覆盖 gap、一线洞察综合 |
| **赋能**（沉淀） | 中（PSL） | 区域最佳实践、团队 onboarding（PSL 视角） |

### 职责 → 产出物
| 职责 | 产出物 | 合规护栏 |
|---|---|---|
| 中央策略本地化 | 区域执行计划（区域格局+资源+时间线） | 部分 |
| 区域活动执行 | 区域学术会/科室会策划、执行清单、合规留痕 | **是** |
| 中央-区域对齐 | 双向对齐 brief（策略下沉 + 反馈上传） | 否 |
| 客户覆盖运营 | 客户分层清单、覆盖 gap、拜访/触点计划 | 部分 |
| 一线反馈闭环 | 结构化区域洞察 → 回流中央市场 | 部分 |

### KPI（推断）
区域计划落地率、区域活动执行质量与合规、客户覆盖率、中央-区域协同有效性。

## 3. 销售管理层（sales-mgmt）

> 圈长 LEL（Local Ecosystem Lead，地区经理）及以上（REL/RCL）。**People manager**，非一线代表拜访执行。

### 岗位画像
- **性质**：团队管理者（people management）+ 业务结果负责
- **策略角色**：把区域/团队目标拆解落地、驱动团队达成；辖区与资源分配
- **核心动词**：coach（教练）/ review（复盘）/ manage（团队）/ drive（达成）/ allocate（资源）
- **硬技能**：随访辅导、业绩归因、1:1 与绩效面谈、辖区管理、业务例会
- **高合规敏感职责**：团队激励（**不得与处方/采购量硬挂钩**）、辖区资源分配、数据分级

### 角色权重
| 角色 | 权重 | 具体含义 |
|---|---|---|
| **助理**（执行） | 高 | 1:1 议程、复盘会材料、业务例会包、团队沟通稿 |
| **参谋**（决策） | 高 | 业绩差距归因、辖区/资源优化、达成预测——管理层决策支持权重高于 IC |
| **赋能**（沉淀） | 高 | 随访辅导/教练、团队 onboarding、最佳实践沉淀——people manager 的核心 |

### 职责 → 产出物
| 职责 | 产出物 | 合规护栏 |
|---|---|---|
| 随访辅导 | 随访观察 → 结构化辅导反馈、改进计划、跟踪 | 部分 |
| 业绩复盘 | 目标 vs 实际差距归因、行动建议、复盘会材料 | 部分（数据分级） |
| 1:1 与团队沟通 | 1:1 议程、绩效面谈稿、改进对话（PIP）、激励沟通 | **是（激励不与销量硬挂钩）** |
| 辖区/资源管理 | 辖区划分、目标分解、资源/覆盖分配、拜访计划 | 部分 |
| 业务例会/QBR | 月度/季度业务回顾包（销售+市场+客户整合） | 部分 |

### KPI（推断）
团队达成率、辅导/教练有效性（团队能力提升）、辖区运营效率、团队保留与敬业度。

## 4. 合规要点（三类人群通用，重点各异）

> 后续替换为罗氏内部 SOP。当前基于 RDPAC 公开准则与通用原则。完整规则见 `compliance/guardrails.md`。

- **讲者管理**（中央市场重）：遴选基于学术资质、不与处方量挂钩；劳务符合 FMV；场次/年度上限留痕；利益冲突申报；内容循证不 off-label。
- **客户互动**（区域市场重）：互动记录合规登记；不与产品推广不当挂钩；客户 PII 不入非授权系统。
- **团队激励**（销售管理重）：绩效与激励沟通**不得与处方/采购量直接挂钩**；辖区资源分配留痕。
- **数据分级**（三类通用）：销售/客户/医院名单等内部敏感数据不外传、不写入可外发产出、不进 git（见客户分级知识包的合规注记）。

## 5. 对 Demo 交付形态的建议

三类人群各有高频高价值场景，建议优先跑通：

- **中央市场**：双语汇报生成、竞品简报、讲者管理+合规自查、物料+MLR 自查
- **区域市场**：区域计划落地、中央-区域对齐 brief、客户分层与覆盖
- **销售管理**：随访辅导反馈、业绩复盘归因、辖区管理、data-analysis 数据分析

> 每个场景都体现"助理/参谋/赋能"三角色，并覆盖对应人群的合规重点。
