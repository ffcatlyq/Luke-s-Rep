The Roche layout system is derived from the logo and should be used across all media to compose and structure information. It follows a simple **ABA **system which takes the proportions of the Roche hexagon to divide space into two or three components.
_(video: Roche_Brand_Portal_Animation_Grids.mp4)_

> **[info]** Average users do not need to create layouts using this system as all standard templates are created with this system and available in the [templates section](https://branding.roche.com/document/29).

The system divides space into two equal parts; A + B. The proportions of the parts are as follows:

- **A** is each 22.5%, therefore A + A is 45%
- **B** makes up the remaining 55% of space
- Therefore **A + B + A** **= Roche logo**
