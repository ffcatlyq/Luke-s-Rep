The ABA system can be used as a means of separating information, denoting hierarchy and defining space for text and photos. These spaces can be more clearly defined by introducing a key line.

The ABA system is applied in much the same way across digital media and print. Landscape formats can use the ABA system vertically and horizontally for flexibility across this format. For a phone format only the vertical space will be divided using the ABA system.

Integration of the Roche logo in print

If the column system is used with the Roche logo then the grid needs to derive from the logo to ensure content optically aligns when the logo and content sit on the same margin. Follow the directions as outlined on this page.
Integration of the Roche logo in digital
The system of setting up the column system in digital is much the same as setting up for print. However, the positioning of the logo and the clear space used to set up the margins are different in digital. The grid should also comprise 12 columns or a multiple within 12 e.g. 1, 2, 3, 4, 6.
