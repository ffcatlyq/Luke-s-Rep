# 看板配方

按场景选卡片和图。目标是"一眼看全"，别塞太多——KPI 卡 4–6 个、图 3–4 个为宜。

## 配方 1：月度/季度业绩看板（例会用）

- **KPI**：总达成率、销售额、环比增长、目标完成进度
- **图**：
  - `bar` 各大区达成率
  - `line` 月度销售趋势
  - `barh` Top/Bottom 辖区排名
- 接 `business-review` / `performance-review` 作开场概览。

## 配方 2：区域达成一览（区域负责人）

- **KPI**：本区达成率、覆盖率、活动数、讲者数
- **图**：
  - `bar` 各医院分级达成（C30/T70/T300）
  - `line` 本区月度趋势
  - `pie` 产品结构
- 接 `regional-plan` / `regional-event`。

## 配方 3：市场份额看板（PM/中央）

- **KPI**：整体份额、份额环比、领先/落后产品数
- **图**：
  - `pie` 竞品份额格局
  - `line` 份额趋势
  - `bar` 各产品份额
- ⚠️ 份额对比若对外须循证、走 MLR，不夸大不 off-label。

## 配方 4：覆盖/客户看板

- **KPI**：目标客户数、覆盖率、高潜覆盖率、频次达标率
- **图**：
  - `bar` 各分层覆盖率
  - `barh` 覆盖 gap Top 辖区
- 接 `customer-segmentation` / `territory-management`。

## 组织原则

- KPI 卡放最重要的 4–6 个结论性数字，放最上面。
- 图从"整体 → 拆解 → 排名"排序，读者视线自然向下。
- 每张图一个信息点，标题写结论不写"图1"。
- 数值直接标在条/点上（脚本已内置），少让读者猜刻度。
