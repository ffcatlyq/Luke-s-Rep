# 常见错误模式 — 数据核对方法论

数据审计中反复出现的 10 类错误。**案例已去具体公司/药名，改写为通用形态**——
保留的是"错在哪、怎么防"的教训，不评价任何机构。适配自通用技能库的真实审计经验。

> 用法：审计博文/物料时逐条对照本清单，判断每个数字是否踩了这些坑。

## 1. 凭记忆引用数据

- **形态**：把印象里的百分比/样本量直接写进稿子（如记成 9.2%，原文实为 11.15%）。
- **教训**：记忆中的数字必须回溯原文验证后才能输出，偏差常在 1–2 个百分点级别，足以误导。

## 2. 张冠李戴（论文归属错误）

- **形态**：同一作者不同年份的两篇论文，把 A 年的数据挂到 B 年的 PMID 上。
- **教训**：同作者多篇论文的数据不能混用；每个数字锁定到**确切 PMID + 年份**。

## 3. 论文标题/项目全称虚构

- **形态**：凭缩写"反推"一个听起来合理的全称，或自编论文标题。
- **教训**：项目全称、论文标题必须从 PubMed / 原文**逐字复制**，不得自行拼造。

## 4. ClinicalTrials.gov ID 错误

- **形态**：NCT ID 写错一位，指向了完全不同的另一项研究。
- **教训**：NCT ID 必须用 ClinicalTrials.gov API 验证 **sponsor + title** 与所述一致。

## 5. 引用元数据错误

- **形态**：卷/期/页码、文章号写错（如 387(4):327 实为 387(3):205）。
- **教训**：期刊/卷/期/页码/文章号必须从 PubMed eutils 返回值逐字复制。

## 6. 网站数据 vs 论文数据不一致

- **形态**：机构官网/新闻稿的数字与论文原文对不上（网站取整或夸大）。
- **教训**：官网/新闻稿数据不可直接引用，必须回溯**论文原文**为准。

## 7. 摘要未列 ≠ 数据不存在

- **形态**：摘要只报主要终点，次要终点仅在正文；据此判定正文数字"虚构"。
- **教训**：判定"虚构"前必须尝试获取**全文**（PMC XML → 期刊网站 → Europe PMC）。全文不可及时标"摘要未列，需全文确认"，**不得**直接判虚构。

## 8. 归属夸大

- **形态**：把"前员工参与""生态圈成员"夸大为"某公司主导/资助"。
- **教训**：前员工参与 ≠ 公司主导；无法验证的资助/归属声明必须删除或改写为如实的生态圈描述。

## 9. 不可验证数据

- **形态**：引用一个无任何公开来源支撑的数字（如"投入超 X 千万"）。
- **教训**：无法溯源的数字**不得出现**在对外物料中，直接删除。

## 10. 四舍五入不标注

- **形态**：同一指标官网 19.8%、论文 19.7%，未说明精度差异。
- **教训**：精度差异必须统一选用论文值，或明确标注"约"。

## 与合规护栏的关系

以上是"数字准不准"的核对；对外物料还须叠加本仓合规红线（`compliance/guardrails.md`）：
数字准确 ≠ 合规——即便数字无误，仍不得 **off-label**、不得夸大、须**平衡呈现**风险、须标 `[来源：<研究名>]`。
