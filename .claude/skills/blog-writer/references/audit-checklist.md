# 博文数据审计清单

## 审计前准备

- [ ] 通读全文，标记所有数字（包括正文、表格、图注）
- [ ] 列出所有 PMID / DOI / NCT ID / 外部链接
- [ ] 确认每个数字的声称来源

## S 级数字（论文数据）

对每个 S 级数字执行：

- [ ] 用 eutils API 拉取论文摘要原文
- [ ] 逐字比对数字（精确到小数点）
- [ ] 核对单位（%、pp、OR、HR、CI）
- [ ] 核对方向（增加/减少、高于/低于）
- [ ] 核对分母/样本量
- [ ] 如摘要未列，尝试获取全文（PMC XML）再判断

## 引用元数据

对每条引用执行：

- [ ] 期刊名称与 PubMed 一致
- [ ] 年份正确
- [ ] 卷(期):页码 与 PubMed 一致
- [ ] 论文标题与 PubMed 一致（不得自编标题）
- [ ] PMID 链接可访问
- [ ] 项目全称/缩写与论文原文一致

## 归属验证

对每篇引用论文执行：

- [ ] 检查作者 Affiliation 是否含目标公司
- [ ] 检查 COI 声明中的公司关联
- [ ] 检查 Funding 声明
- [ ] 标注关联类型：直接作者 / 前员工 / 资助 / 无关联

## NCT ID 验证

- [ ] 用 ClinicalTrials.gov API 验证 NCT ID
- [ ] 确认 sponsor 与博文声称一致
- [ ] 确认研究标题与博文描述一致

## 修正输出

- [ ] 修正前后对比表
- [ ] 错误分类（记忆偏差 / 来源混淆 / 四舍五入 / 张冠李戴 / 标题虚构）
- [ ] 修改处加 `<u>` 下划线
- [ ] 检查同批次其他数字
