# 药企 / Roche投资者deck叙事方法论(pptx-authoring第三轴)

> **这是"业务know-how"层，不是配色/版式层。** pptx-authoring的三轴适配：① 设计(brand bundle)
> ② 合规护栏 ③ **叙事方法论(本文件)**。做罗氏/药企主题deck时先读本文件定**叙事结构 + 术语 + 框架**,
> 再套brand + 合规——让deck不只"看起来像罗氏",而是"讲得像药企在讲"。
>
> **来源**:蒸馏自Roche公开投资者关系deck(roche.com/investors/downloads,2026-07,5份：Pharma Day 2025
> 168p / Diagnostics Day 2026 153p / JPMorgan 2026 14p / Q1 2026 Results 153p / SABCS Oncology 2025 48p)。
> **口径**:方法论/结构/术语=**耐用**(跨deck稳定，可直接用);具体管线/数字=**易耗**(会过期，
> 举例可用但必须标注来源+日期，别当"真理"焊进工具)。蒸馏非逐字复制(公开IR,内网开源，低敏)。

## I. 宏观叙事弧(deck骨架)

罗氏投资者deck **高度模板化**,几乎所有都走这条弧(观察自5份):

```
1. 封面(deck 名 + 日期)
2. Safe Harbor 免责声明(forward-looking statements)—— 法务硬要求,几乎每份第 2 页
3. Agenda + 讲者(多讲者 deck 每段换人处插讲者页)
4. 集团战略层:Ten-Year Ambitions / "Prevent, Stop, Cure" 战略 / 五大 TA / 增长记录
5. 分部/TA/franchise 深潜(deck 的主体,见 §III 每块的内部弧)
6. Pipeline 总览(Compound 表 / development pipeline / NMEs by 20XX)
7. Finance / Guidance(结果类 deck 才有:sales at CER、guidance confirmed、汇率影响)
8. 签名收尾页:"Doing now what patients need next"(罗氏铁打的最后一页 slogan,5/5 都有)
```

**deck类型 → 弧的裁剪**:
- **旗舰概览(JPMorgan 14p)**:压到极致——封面→免责→"delivering next innovation cycle"→3-4个NME亮点→1个明星资产深潜→pipeline表→收尾。**短deck的模板**。
- **战略日(Pharma/Diagnostics Day 150+p)**:全弧 + 每TA/product area完整深潜 + 多讲者。
- **季度结果(Results 153p)**:Performance → Finance/Guidance → 每分部sales拆解 → pipeline进展。
- **疾病领域事件(SABCS 48p)**:news flow → franchise update → 单病种unmet need/market → 资产深潜。

## II. 幻灯片原型库(archetypes,复用单元)

每种原型有固定"意图 + 内容骨架",做deck时按需拼：

| 原型 | 意图 | 内容骨架 |
|---|---|---|
| **Safe Harbor** | 法务免责 | 整页小字forward-looking disclaimer(套话，可直接复用标准文本) |
| **Strategy overview** | 集团/分部战略框架 | 一个命名框架(如Prevent/Stop/Cure、Ten-Year Ambitions)+ 几支柱 |
| **"Significant progress on X"** | 证明进展/兑现 | 里程碑清单 / 前后对比 / 打勾达成 |
| **Growth drivers** | 谁在拉动增长 | 几个产品/franchise的增长贡献(常配CER%) |
| **Franchise/TA update** | 某治疗领域现状 | 该TA的市场 + 在研 + 近期news flow |
| **Unmet need** | 立论"为什么需要新药" | "Despite advances… high unmet need remains in [病种]"—— 现有疗法局限 + 患者缺口 |
| **Market opportunity** | 市场有多大 | 患者数 / addressable market / 细分(如ER+ BC市场) |
| **Asset positioning** | 单个在研药定位 | "[药名]: Potential to become FIC/BIC in [适应症]"—— 机制差异化 + 竞品对比 |
| **Clinical evidence** | 数据支撑 | Ph II/III结果：OS/PFS、对照、statistical significance;数据未成熟时明说"immature" |
| **Development program** | 布局广度 | 一个药跨多适应症/患者群的Ph矩阵 |
| **Pipeline table**("Compound") | 全景在研 | 表：化合物 × 适应症 × 阶段；"changes to pipeline"标增删 |
| **NMEs milestone** | 未来供给 | "Up to N NMEs with launch potential by 20XX" |
| **Finance/Guidance** | 财务 | sales at CER、汇率影响、guidance confirmed |
| **News flow** | 近期催化 | "Positive Ph III results for [药] in [病]";按季度列 |
| **Signature close** | 收尾 | "Doing now what patients need next" |

## III. 每块深潜的微观弧(讲单个资产/TA的套路)

罗氏讲一个在研药，几乎总按：**疾病/未满足需求 → 市场机会 → 资产定位(FIC/BIC + 机制差异)→ 临床证据(Ph II/III数据)→ 开发广度(多适应症)→ 里程碑/news flow**。

例(SABCS ER+ 乳腺癌块):market opportunity → "high unmet need remains" → giredestrant comprehensive program → Ph III lidERA数据 → Itovebi扩展潜力。**这条微观弧是"药企怎么把一个分子讲成投资故事"的核心方法论。**

## IV. 术语表(glossary,标准药企/罗氏用法)

做药企deck必须用对这些(频次=在5份deck里的出现次数，示相关度):

| 术语 | 含义 | 备注 |
|---|---|---|
| **CER**(457) | Constant Exchange Rates固定汇率 | 罗氏报销售增长的默认口径(剔除汇率),几乎所有sales数字都 "at CER" |
| **Ph II / Ph III**(450/308) | 临床二期/三期 | 三期=注册性关键试验；deck里进展基本按Ph阶段讲 |
| **NME**(136) | New Molecular Entity新分子实体 | "up to N NMEs by 20XX" 是罗氏讲未来供给的招牌指标 |
| **FIC / BIC**(311/26) | First-in-Class / Best-in-Class | 资产定位的核心话术：同类首创or同类最优 |
| **SoC**(202) | Standard of Care标准疗法 | "potential to become new SoC" = 改写标准 |
| **OS / PFS**(83/32) | Overall Survival / Progression-Free Survival | 肿瘤终点；OS金标准，"immature"=随访不足未到分析点 |
| **unmet need**(22) | 未满足的医疗需求 | 立论基石：现有疗法不够好 → 新药有位置 |
| **peak sales**(43) | 峰值销售 | 资产商业价值的常用量化 |
| **guidance**(5) | 业绩指引 | "guidance confirmed/raised" |
| **franchise / TA**(16/13) | 产品线 / Therapeutic Area治疗领域 | 罗氏五大TA:Oncology/Hematology、Neurology、Immunology、Ophthalmology、CVRM(心血管肾代谢) |
| **companion diagnostic**(24) | 伴随诊断 | 罗氏Pharma×Diagnostics协同的独有叙事(个性化医疗) |
| **biomarker**(53) | 生物标志物 | 患者分层 / 精准用药 |
| indication(108) | 适应症 | 一个药可"indication expansion"扩多病种 |

Roche独有框架：**Ten-Year Ambitions**、**"Prevent, Stop, Cure"**(2024 rollout的集团战略)、**Pharma×Diagnostics协同**(伴随诊断)、五大TA。

## V. 叙事voice / 惯例

- **数据前置、结论先行**:标题就是结论("Strong Group sales growth at +6% at CER"),不是"Q1销售情况"。
- **风险-收益诚实**:数据未成熟就写 "immature";"potential to" 而非打包票——投资者deck的可信度靠这个。
- **患者叙事收尾**:永远回到 "Doing now what patients need next"——科学/商业最终锚回患者价值。
- **franchise视角**:讲增长按franchise/产品拆，不是笼统"销售涨了"。
- **catalyst意识**:news flow / 里程碑 / "by 20XX" 给投资者可跟踪的时间锚。

## VI. pptx-authoring怎么用(第三轴接线)

做罗氏/药企主题deck时：
1. **定弧**:按 §I选deck类型的弧(旗舰概览 / 战略日 / 结果 / 疾病事件)排页清单——这是design_spec §IX(内容大纲)的**药企版起点**。
2. **拼原型**:每页从 §II原型库选，按 §III微观弧组织单资产/TA深潜。
3. **用对术语**:§IV glossary——sales标CER、资产讲FIC/BIC、立论用unmet need→market→positioning→evidence。
4. **上voice**:§V——标题写结论、风险诚实、收尾回患者。
5. 再套brand(roche-blue/roche-dark)+ 合规(无PII/HCP/患者数据；公开信息)。

**边界(诚实)**:本方法论管"怎么讲"(结构/术语/框架),**不提供具体管线事实**——那些每篇不同、会过期，必须用户提供或引用带日期的公开源，agent别编。工具让deck良构、on-message、术语专业，内容仍需人填。
