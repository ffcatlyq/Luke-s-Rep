# 技能：工作邮件起草（Email Authoring）

> 角色：**助理**。起草专业、礼貌、商务向的中文（或中英）工作邮件——给上级、跨部门、KOL/讲者、外部合作方。核心价值是**去 AI 味**：写得像真人 PM 发的邮件，不是模板拼接。
> 移植自通用技能库（silicon-hitchhiker），已适配 PM 场景与合规护栏。

## 触发条件
用户诉求包含："写邮件""起草邮件""draft email""发邮件给 X""回邮件给 X"，或给出收件人 + 邮件意图（如"给 Anand 写一封 follow-up"）。
- 不触发：简短聊天回复走 `chat-reply.md`；对外推广物料走 `promo-material-mlr.md`。

## 输入（缺失则追问）
- 收件人 + 抄送（决定称呼与语气）
- 关键事项（一句话总结）
- 期望对方做什么（决策 / 提供信息 / 知会 / 请教）
- 是否有截止时间
- 语气倾向：专业请教 / 同事级对接 / 正式通知

用户已给齐则跳过追问，直接起草。

## 任务流
1. **判断语气与称呼级别**（见下"称呼分级"）。
2. **起草正文**：开头 1-2 句给上下文（怎么知道这事 / 为什么发），第 3 句起进核心信息。
3. **反 AI 自查**：过一遍下方 checklist，砍掉 AI 痕迹。
4. **合规检查**：涉及产品疗效表述遵循护栏；敏感/未公开数据标注"内部，勿外传"。
5. **沉淀**：存 `outputs/emails/<日期>_<主题>_邮件.md`。
6.（可选）**推送 Gmail Draft**：若环境接了 Google Workspace，可用 `gmail_compose.py sync` 推草稿让用户在 Gmail 审核。**默认不自动发送**——邮件不可逆，发送由用户在 Gmail UI 手动完成。

## 称呼分级

| 收件人 | 用法 | 反例 |
|---|---|---|
| 资深前辈 / 客户 / KOL / 长辈 | "X 老师"、"X 总"、"Dear X" | 直呼名字 |
| 同级同事 | "X，" 或 "Hi X" | "X 老师"过于客气 |
| 多人收件 | "几位好"（中文）/ "Hi all" | "Hi几位好"（中英混搭）/ "Dear team"（AI 味） |

## 主题词原则
- 用明确动词："请教：X"（谦逊短）/ "X — 内部对接咨询"（平级/上行）/ "通知：X（截止日期）"（下行）
- 含截止日期直接写进主题：`请教：xxx（5/29 截止）`
- 不用："在跟吗？"、"看下"、"快速看一下"、"关于那个事"、全大写 `URGENT:`

## 反 AI 写作规则（精华，起草后逐条自查）

**基础格式：**
- [ ] 不加盘古之白（CJK 与拉丁/数字紧贴："100+罗氏同事"而非"100+ 罗氏同事"）
- [ ] 称呼级别匹配收件人关系
- [ ] 超链接用 `[文字](url)` 格式，不裸贴 URL
- [ ] 矩阵/对照表/清单**直接 inline 渲染**（markdown table），不写"详见 X.jpg"
- [ ] 不 inline 长图片（海报/长截图走链接）
- [ ] 不手写签名（由 Gmail 设置统一管理）
- [ ] 无 emoji（包括 ✅❌🚀⚠️ 等"功能性"图标）
- [ ] 加粗只用在关键数字/日期/姓名

**AI tic（起草后精简）：**
- [ ] 无 AI 开场白（"I hope this email finds you well"、"事情是这样"、"首先"、"总的来说"、"为了更好地"）
- [ ] 无 AI flattery（"比 X 权威很多"、"写得真好"等贴金）
- [ ] 无 meta-分析尾巴（列完事实不再加"两者 X 都对不上"，读者自己能读出）
- [ ] 无 either-or 犹豫备选（有建议就直说，归属到具体提议人）
- [ ] 无冗余 fillers（删"这边/一直/着/那边"）
- [ ] section 标题中性（"补贴口径的确认"而非"补贴口径有冲突"）
- [ ] 无过度限定从句（前文已闭环不重复）
- [ ] 无 deferred-action 尾巴（"已记到 X"后不再加"建议下次一起处理"）

**适度加值（这几类"加"是对的）：**
- [ ] 第一次提外部人加机构（"科经委刘锐老师"，帮收件人 calibrate 信源）
- [ ] deliverable 后顺带 forward-looking value（"台账已映射，后续可自动填报申请表"）
- [ ] 遇到做不到的事直接承认 + 给替代方案，不含糊、不推给"以后"

## 产出模板
```markdown
---
to: [alice@roche.com]
cc: [bob@roche.com]
subject: <明确动词 + 主题（含截止日期）>
---

<称呼>，

<开头 1-2 句：上下文，为什么发这封>

<核心信息：结论先行，需要对方做什么>

<如有对照信息，inline 表格>
| 项目 | 值 |
|---|---|

<如有下一步 / 行动项>
```

## 合规检查（本技能）
- [ ] 产品疗效表述有循证、不夸大、不 off-label
- [ ] 敏感/未公开数据标注"内部，勿外传"，C3/C4 数据不外发
- [ ] 对外邮件（客户/KOL/讲者）涉及推广内容时，先走 `promo-material-mlr.md` 做 MLR 自查
- [ ] 发送为不可逆操作——由用户人工确认发送，技能不自动 send
