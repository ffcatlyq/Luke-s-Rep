# 分析前质询透镜 — 从哪些角度审问题

> 五步法全是量化信息，且它的精神是"别被表面问题带跑、找真漏点"。所以**给业务分析结论前，先用这套透镜审一遍问题**——尤其是数字、人、和外部约束。
> 这是"从哪找问题"的检查清单，**不是逼你每次问十遍**。信息够了就直接分析；只把"模糊且会改变结论"的疑点转成反问。

## 怎么用（三步）

1. 用下面**三层透镜**扫问题，标出可疑处。
2. 判断每个可疑处：**会不会改变结论走向？** 不会 → 带假设继续；会 → 进第 3 步。
3. **有节制反问**：只问会改变结论的、一次问全**最多 1–2 个**、讲清为什么问；够了就停，别车轱辘。

判据对齐 AGENTS.md 4.1「意图清晰度 × 代价」：清晰→直接做；模糊且影响结论→先问；模糊但代价低→带假设先做。

---

## 第 1 层 · 数字层：这些数字可信吗？

| 透镜 | 问自己 | 触发信号 |
|---|---|---|
| **口径自洽** | 分子分母对得上吗？留存率乘起来合理吗？时间窗/患者范围一致吗？ | 比率 >100%、各步数字对不上 |
| **突变异常** | 有跳水/尖峰吗？单月波动还是趋势拐点？样本会不会太小？ | 某月骤变、月收治个位数 |
| **沉默证据** | 谁不在数据里？最大的桶是不是恰恰"待补充"？ | "其他组待补"、从没被诊断的患者、缺失的产品线 |

> ⚠️ **沉默证据最易漏**：没出现在表里的人群，往往是最大漏点。缺失的数字标"待补"，不拿臆测硬算。

---

## 第 2 层 · 归因层：这真是根因吗？

| 透镜 | 问自己 | 触发信号 |
|---|---|---|
| **痛点错位** | 提问者关心的那步，真是留存最低的那步吗？ | 问"份额"但数据显示卡在"收治" |
| **归因方向（左右口袋）** | "流失"是内部分流还是真外流？ | 一个组降、另一个组同期升 |
| **结构 vs 观念** | 障碍是"不信"（需学术教育）还是"够不着"（需准入/支付/流程）？ | "不可及""不用"——先分清是哪种 |
| **一因多果** | 多个症状是不是同一上游根因？ | 两三个问题同时出现、彼此呼应 |
| **时序巧合** | 变化发生在何时？同期还发生了什么？ | 某人上任/某政策落地 ≈ 指标转折 |

> ⚠️ **结构 vs 观念别混**（本 skill 作者曾在此栽过）：把"准入/支付障碍"当"观念问题"去做学术教育，方向全错。先判断是"不信"还是"够不着"。

---

## 第 3 层 · 人与局层：我看对人和外部约束了吗？

| 透镜 | 问自己 | 触发信号 |
|---|---|---|
| **⭐ 行为矛盾优先** | 有没有自相矛盾的信号？就矛盾发问，它比平铺数据强得多。 | **认可却不用 / 准入却不可及 / 最会用却在丢 / 参会却拒预汇报** |
| **角色杠杆错配** | 每个关键人，我是用对维度判断其价值吗？ | 把"曾推动准入的人"当"推不动的死节点" |
| **政策外部手** | DRG / 药占比 / 医保 / 停限控 / 集采，是不是那只看不见的手？ | 创新药被压、床位受限、自费门槛 |

> ⭐ **行为矛盾是信号最强的一棱**。人不会无缘无故自相矛盾——矛盾点背后一定有一个可干预的断点，顺它挖，直达根因。

## 长海医院实例（这套透镜怎么救场）

> 案例：提问者问"长海优罗华**提份额**"，预期"改变两位科主任观念"。用透镜扫出的问题：

| 透镜 | 扫出什么 | 对结论的影响 |
|---|---|---|
| 突变异常 | 优罗华转化率 50%→6月30%，接近腰斩 | 基准存疑，先归因单月 vs 趋势 |
| 沉默证据 | "其他 3 组待补充"可能是最大盘子 | 撬动排序算不准，需补 |
| 痛点错位 | 问"份额"，但真漏点可能在"收治"（若那步留存最低） | 主攻方向可能要改 |
| 归因方向 | 最会用的淋巴瘤带组在**丢患者**，同期新主任收治**骤增** | 大概率内部分流，非外流 |
| 时序巧合 | 倪雄年初上任 ≈ 淋巴瘤收治增 ≈ 该带组降 | 佐证内部分流假设 |
| **行为矛盾** ⭐ | **杨主任去年亲手准入 glofit、认可其疗效，如今却停用；且新主任"不可及"** | **一因多果的钥匙**——停用+不可及很可能同源 |
| 结构 vs 观念 | glofit 已准入 → "不可及"不是"没进院"，是准入后被某障碍架空 | 打法从"学术教育"转向"查用药路径/准入激活" |
| 角色杠杆错配 | 杨主任作"优罗华转化目标"=低杠杆；作"glofit 准入推手/诊断节点"=**高价值** | 定性从"维持关系即可"改为"重点深访挖停用根因" |

**透镜筛出的唯一核心反问**（替掉一堆平铺追问）：
> glofit 去年已由杨主任准入，为何他现在停用、且对新主任不可及？
> A. 半退休不接新患者　B. DRG/药占比/停限控限制　C. 出过安全性事件转谨慎　D. 临时准入到期　E. 冠军退任无人接棒

一个答案，同时决定 glofit 这条线怎么打 + 杨主任是"维持"还是"深访"。

**教训**：一开始我问了"高罗华不可及=未进院 vs 个案受限"——但材料已写明杨主任在任期间准入过，**未进院本可自行排除**。这就是没把材料读透、拿反问代替思考。透镜清单就是为了逼自己先扫完再问。

---

## 一句话

质询不是多问，是**问对**：先用三层透镜把数字、归因、人局扫一遍，尤其盯**行为矛盾**；只把会改变结论的疑点转成 1–2 个反问，够了就直接分析。
