# 五步患者流漏斗 — 每步详解

> 忠实还原洪晓老板五步法主干。每步给：**它是什么、衔接指标怎么算、典型漏点、诊断问题、产品对应**。
> ⚠️ 所有业务目标/份额数字为**内部经营口径**，运行时从知识包读，本文件不硬编码具体数值。

## 漏斗全景

淋巴瘤患者从"社区里一个不典型症状"走到"在这家医院规范足疗程治疗"，中间每一步都可能漏人。业务流失 = 每步漏点的累积。

```
社区不典型患者
  │ 1. 首诊鉴别   ──漏──►【源头漏诊】
  ▼   前端早筛 → 诊断率
明确诊断的患者
  │ 2. 明确诊断   ──漏──►【分母蒸发】
  ▼   导入率
收治入院的患者
  │ 3. 收治均衡   ──漏──►【患者隐形】
  ▼   轮转率
选对方案的患者
  │ 4. 治疗方案   ──漏──►【方案不规范】
  ▼   转化率
足周期规范治疗的患者
  │ 5. 周期规范   ──漏──►【方案篡改和延误】
  ▼   DOT
持续的业务增长
```

## 逐步详解

### 步 1｜首诊鉴别 —— 前端早筛 → 诊断率

- **是什么**：不典型症状患者能否被及时识别、导向病理取材。
- **典型漏点【源头漏诊】**：发病不典型，散落在外科、发热门诊、内科等，缺乏及时鉴别能力，走不到取材/病理，延误诊断或误诊。
- **衔接指标**：诊断率 = 病理检出淋巴瘤患者数 / 应被识别的疑似患者数（前端早筛质量）。
- **诊断问题**：前端科室是否有淋巴瘤早筛意识？外科—血液的转诊绿通是否存在？
- **产品对应**：全品牌共性入口——这一步漏，后面所有产品都没机会。

### 步 2｜明确诊断 —— 导入率

- **是什么**：疑似患者能否在本院/本地明确病理诊断并导入治疗。
- **典型漏点【分母蒸发】**：地市/基层缺淋巴瘤病理诊断能力、诊断周期长，或无法明确诊断；患者无人指导、盲目问诊流失。
- **衔接指标**：导入率 = 病房收治的 1L/RR DLBCL 患者数 / 病理检出淋巴瘤患者数（除单纯外院病理会诊）。
- **诊断问题**：病理科取材固定标准是否规范？病理→临床的患者流转是否顺畅？诊断周期多长？
- **产品对应**：决定进入治疗的"分母"大小——分母越小，所有产品的绝对量越小。

- **① 先纯化分母（关键）**：导入率的分子分母都要"洗干净"再算，否则率失真——
  - 分母剔除**不能导入的患者**：如外院送来本院病理科**仅做会诊/检测**、治疗不在本院的，要剔除。
  - 警惕**倒挂**：若收治数 > 本院检出数，说明有患者**外院带诊断/方案**而来（分母口径要单列）。
  - 病理检出数甚至可能低于收治数——同样是外院检出、本院治疗，需厘清来源。
- **② 主动导入 vs 被动导入**（两类漏点，解法不同）：
  - **被动导入不足**：本院已检出却没进血液科（病理→血液断链）→ 修转诊闭环、补病理专人。
  - **主动导入受限**：想收但**床位不够** → 要么提高**床位轮转率/缩短住院时间**，要么**借床（如中医科）/ 开发门诊日间**扩大可收治数。（注：床位受限本质多属步3，但直接压制导入，需一并看）
- **③ 做大分母（分母过小时的第一要素）**：检出基数太小时，提升率不如做大分母——
  - 从其他科室要送检：外科/眼科/胃肠科/耳鼻喉科/呼吸科等不典型患者散落处 → 送病理 → 送血液科。
  - 综合医院尤其要盯**其他外科**，这部分占比往往更大。
- **④ 拆到具体人（病理科 raw data 反查）**：从病理科原始数据往回查——
  - 某外科主任是谁、专门送病理组织的护士是谁、能检出该瘤种的病理科医生是谁。
  - 拆到人才能定位可干预的具体环节。⚠️ 个人信息脱敏、不进 git。
- **⑤ 遗漏量化**：其他外科检出淋巴瘤的有多少、其中多少送到了血液科、**遗漏多大、能否做工作**。
- **⑥ 分阶段落地（导入率阈值驱动）**：导入归拢不是一步到位，用导入率作阶段闸门——
  - **建机制**（第0-2周）：先把本院已检出患者导入闭环（报告标注、专人对接、微信群、每月复盘）。
  - **导入率 ≥60% → 启动归拢**：向其他首诊科室扩展，按送检量排序先攻前三名未覆盖科室。
  - **导入率 ≥75% → 全面归拢**：每月 1 个科室做归拢 MDT（血液+首诊+病理，双科主任必出席）。
  - ⚠️ 别在导入机制没建好时就急着归拢外部科室。可打勾的落地工具见 `templates/import-consolidation-checklist.md`。

### 步 3｜收治均衡 —— 轮转率

- **是什么**：确诊患者能否被本院及时收治、床位周转是否顺畅。
- **典型漏点【患者隐形】**：地市医院留不住患者、大量涌入 C30；C30 收治饱和、科室挑病人；患者溢出到非目标科室/医生。
- **衔接指标**：轮转率 = 接受 X 罗华治疗的患者数 / 病房收治的目标患者数（收治转化 + 床位周转）。
- **诊断问题**：是否还有很多门诊患者没法收治？排床流程能否缩短住院天数？有无日间/门诊化路径？
- **产品对应**：床位是全品牌共享的瓶颈——排床不畅同时压制多个产品。

### 步 4｜治疗方案 —— 转化率

- **是什么**：收治患者能否选到规范、优选的治疗方案。
- **典型漏点【方案不规范】**：C30 优先临床入组、DRG 考核压缩创新治疗；地市医院观念更新不及时、国产竞争；没能选择 1L 优、2L 高方案。
- **衔接指标**：转化率 = 用目标方案的患者数 / 接受治疗的目标患者数。
- **诊断问题（分品牌）**：优罗华——应该用 3.X 支的是否用到？高罗华——达到 CR 的患者是否用足 12 疗？佳罗华——1-8-15 是否规范？
- **产品对应**：这一步最需要**分品牌**逐个查方案规范性。
- **深化诊断**：转化率最需"分品牌 + 拆到人"——分层 × 关键处方人二维拆解、处方动机三分类见 `conversion-diagnosis.md`；产品特定口径见 `knowledge-packs/hematology/playbooks/`。

### 步 5｜周期规范 —— DOT

- **是什么**：选对方案的患者能否坚持标准周期、足疗程。
- **典型漏点【方案篡改和延误】**：C30 的 21 天周期被床位短缺打破；患者无引导回流当地，治疗方案被篡改；未坚持标准周期。
- **衔接指标**：DOT（Duration of Therapy）——足疗程/足周期比例。
- **诊断问题**：患者回疗间隔是否大于 21 天？回疗患者能否及时入院？佳罗华两年每 2 个月回来维持是否做到？
- **产品对应**：维持/多周期产品（佳罗华维持、高罗华 12 疗）在这一步最敏感。

## 两种模式怎么配合

| | 分品牌分析 | 全品牌解题 |
|---|---|---|
| 看什么 | 每个产品对自己业务目标差多少 | 哪个漏点同时卡住最多产品 |
| 落在哪步 | 主要在步 4/5（方案、周期） | 贯穿步 1-3（早筛、诊断、收治）多为共性漏点 |
| 产出 | 各品牌 gap 清单 | 一个主攻漏点 + 一组动作（MDT/排床/专人）|

> 决策顺序：先分品牌看清各产品 gap → 再全品牌找那个"解一个能带动多个"的共性漏点 → 一次只主攻一个（见 `methodology.md` 的 TOC 聚焦）。

## 常见解法库（来自实战，动作层）

| 漏点 | 常见动作 |
|---|---|
| 源头漏诊 / 分母蒸发 | 血液科淋巴瘤早筛教育、病理科取材固定标准、外科—血液流转绿通、淋巴瘤+病理专人设立、**从其他外科要送检做大分母** |
| 主动导入受限（床位卡）| **缩短住院时间 / 提高床位轮转率、借床（如中医科）、开发门诊日间**——扩大可收治患者数 |
| 患者隐形 / 收治不均 | 优化住院排床流程、缩短住院天数、建设住院/门诊日间、精细化运营解除停限控 |
| 方案不规范 | 定期病理+临床诊断复盘会、分品牌方案规范沟通（循证以说明书为准）|
| 篡改和延误 | 回疗引导、及时入院机制、维持治疗提醒 |
| 跨步协同 | 定期规律的血液+病理+前端科室 MDT 交流 |

> ⚠️ 涉及治疗方案/周期规范的沟通须**以产品说明书为准、不超适应症**，对外物料经 MLR。
