## 分阶段逻辑（导入率阈值驱动）

导入归拢是**分阶段推进**的，用导入率作为阶段闸门：

```
第0-1周 摸底  →  第1-2周 建导入机制  →  每月导入追踪
                                            │
                          导入率 ≥60% → 启动归拢 + 优化导入
                          导入率 ≥75% → 全面归拢
```

> 逻辑：先把本院已检出的患者导入闭环(建机制)，导入率达 60% 再向外拓（从其他首诊科室归拢），达 75% 全面归拢。**别在导入机制没建好时就急着归拢外部科室。**

## 阶段二 · 第1-2周：建立导入机制（面向区域淋巴瘤中心）

**目标：促进血液/首诊科室 ↔ 病理的对话**

| 事项 | 行动 | 是否完成 |
|---|---|---|
| 报告标注 | **1.1** 报告标注就诊信息："建议至血液科/淋巴瘤病区/淋巴瘤专病门诊就诊"+门诊/住院地址、电话 | |
| （降级方案）| **1.2** 若 1.1 无法落地：病理窗口在报告上标注/加盖"建议至血液科就诊"，或附专病门诊信息卡片 | |
| 专人对接 | **2.1** 血液科、病理科各设淋巴瘤专人对接医生，对检出患者一对一沟通，完成挂号/入院等后续 | |
| 微信群 | **2.2** 血液科&病理科建专属沟通群，第一时间通知检出患者，血液科专人当天联系患者预约 | |
| （选填）信息科 | 通过信息外呼，将检出患者自动提醒血液科对接（视实际情况）| |

### 每月导入追踪

| # | 内容 | 填写 |
|---|---|---|
| 1 | 血液科&病理科每月复盘：检出数 vs 收治数 + 协作方向 | 是否完成： |
| 1.1 | 病理科淋巴瘤检出数？ | |
| 1.2 | 血液科淋巴瘤收治数？ | |
| 1.3 | **导入率**？（1.2 ÷ 1.1，自行计算）| |
| 1.4 | 未导入的原因及优化：①哪个科室需定向沟通？②院内绿通需优化？③患者联系后离开→优化沟通话术 | |
| 2 | 导入机制推进的卡点和解决办法？ | |

**目标：向其他首诊科室扩展，把散在外科的患者归拢到血液科**

| 科室排序 | **1** 按各科室送检淋巴瘤检出数从高到低排，先从**前三名未覆盖科室**开始 | 本月覆盖科室： |

| MDT 频率 | **5** 每月 1 个科室 | 本月是否完成： |

## 合规

- **严禁科室/医生个人层面的处方统计**——本工具只跟踪检出/收治/导入等诊疗流数据，不落处方量、不落患者可识别信息。
- 仅内部使用、脱敏、不外传、不进 git 填好的真实版本。
- MDT 学术内容以说明书为准、不超适应症；对外物料经 MLR。
