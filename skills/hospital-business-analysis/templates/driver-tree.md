# 患者流 Driver Tree — 算式模板

> 把五步漏斗做成一条乘法链，量化每步贡献，找出撬动潜力最大的因子。配合 `references/methodology.md` 层 1。
> ⚠️ 示例数字为**演示占位**，非真实业务口径；实际用院内数据替换。

## 主算式

```
单院业务量
  = 合格患者池
  × 诊断率      (步1：病理检出 / 疑似)
  × 导入率      (步2：收治 / 病理检出)
  × 轮转率      (步3：治疗 / 收治)
  × 转化率      (步4：目标方案 / 治疗)
  × DOT系数     (步5：足周期比例)
```

## 因子拆解树

```
业务量
├── 合格患者池 ── 区域发病 × 本院可及份额
├── 诊断率 ────── 前端早筛意识 × 病理取材能力 × 转诊绿通
├── 导入率 ────── 病理→临床流转 × 诊断周期 × 患者指导
├── 轮转率 ────── 床位周转 × 排床效率 × 日间路径
├── 转化率 ────── 方案观念 × DRG影响 × 竞争 × 循证沟通
└── DOT系数 ───── 回疗间隔 × 及时入院 × 维持依从
```

## 弹性测算（找撬动点）

对每个因子做"若提升 10%，业务量增加多少"：

| 因子 | 当前值(演示) | 基线业务量 | +10% 后业务量 | 增量 | 排序 |
|---|---:|---:|---:|---:|---:|
| 诊断率 | 0.40 | 100 | 110 | +10 | |
| 导入率 | 0.70 | 100 | 110 | +10 | |
| 轮转率 | 0.50 | 100 | 110 | +10 | |
| 转化率 | 0.60 | 100 | 110 | +10 | |
| DOT系数 | 0.80 | 100 | 110 | +10 | |

> 注：乘法链下,单因子 +10% 对总量的相对拉动相同(都 +10%);**真正的优先级看"哪个因子当前绝对值最低、最容易提升、且卡住最多产品"** —— 即 Cascade 留存率最低 + 改善成本最低者。Driver Tree 的价值是把目标(如份额>70%)锚到具体因子,让动作有落点。

## 与 Cascade 留存率的关系

| 视角 | 读法 | 用途 |
|---|---|---|
| Driver Tree | 乘法预测:改哪个因子、业务量变多少 | 定目标、锚动作 |
| Cascade 留存率 | 每步留存 = 本步/上一步 | 诊断:哪步掉最狠 |

两者同一组因子、两种读法:先用 Cascade 找漏点,再用 Driver Tree 把目标落到因子、估增长空间。
