## 原版结构（提炼，便于检索；细节以原版 pptx 为准）

**核心命题**：中国淋巴瘤患者诊疗场景不连续 → 业务流失。做法：找准漏点、分阶段堵漏、找到持续增长。

**五步患者流漏斗**（每步：环节 → 衔接指标 → 典型漏点）

1. 首诊鉴别 → 前端早筛/诊断率 →【源头漏诊】
2. 明确诊断 → 导入率 →【分母蒸发】
3. 收治均衡 → 轮转率 →【患者隐形】
4. 治疗方案 → 转化率 →【方案不规范】
5. 周期规范 → DOT →【方案篡改和延误】

**两种分析模式**：分品牌分析（各产品对业务目标查 gap）+ 全品牌解题（找卡住最多产品的共性漏点，用 MDT/排床/专人等动作）。
