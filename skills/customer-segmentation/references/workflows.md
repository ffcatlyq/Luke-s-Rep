# Customer Segmentation — 场景工作流

## 场景 1：建立客户分层

**输入**：目标客户/医院清单（含分级、科室、HCP 信息），可用的画像维度数据。

**步骤**：
1. **拉基础数据**：医院分级（C30/T70/T300）、大区、科室、HCP 职级/影响力/潜力/态度。缺哪些先问或标"待补"。
2. **医院维度定档**：直接用 C30/T70/T300。
3. **HCP 维度画像**：按 `methods.md` 的画像维度打分/归档。
4. **叠加分层**：医院分级 × HCP 画像 → 客户优先级（见分层矩阵）。
5. **输出分层清单**：每个客户标优先级 + 关键画像。

**产出**：客户分层清单（见 `templates/segmentation-list.md`）。

## 场景 2：覆盖 gap 分析

**输入**：客户分层结果 + 实际覆盖数据（已拜访/互动记录）。

**步骤**：
1. **定覆盖标准**：各分层应达的覆盖频次/深度（来自 A/B/C 策略）。
2. **算实际覆盖**：用 `data-analysis` 拉每个客户的实际互动。
3. **覆盖漏斗**：目标 → 已覆盖 → 深度互动 → ……逐层看转化，定位断点（见 `methods.md`）。
4. **gap 清单**：应覆盖未覆盖、覆盖不足的客户，按优先级排序。

**产出**：覆盖 gap 清单 + 漏斗（见 `templates/coverage-gap.md`）。

## 场景 3：分级覆盖策略

**输入**：分层结果 + gap 分析 + 可用资源。

**步骤**：
1. **设 A/B/C 分级**：把客户优先级归为 A/B/C（见 `methods.md`）。
2. **每级定策略**：互动深度、频次、渠道组合（面对面/数字，接 `omnichannel-engagement`）、内容重点。
3. **资源匹配**：向 A 类倾斜，校验团队产能（接 `territory-management`）。
4. **落地**：转化为覆盖计划/call plan。

**产出**：分级覆盖策略（见 `templates/tiered-strategy.md`）。

> 全程数据敏感，产出默认内部使用。
