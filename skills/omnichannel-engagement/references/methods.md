# 全渠道方法论

## 客户旅程阶段

典型 HCP 旅程（按实际产品/客户调整）：

| 阶段 | 客户心态 | 互动目标 |
|---|---|---|
| 认知 Awareness | 不了解/初闻 | 建立认知、传递核心信息 |
| 兴趣 Interest | 想了解更多 | 提供循证、深化理解 |
| 尝试 Trial | 考虑用于合适患者 | 支持临床决策、答疑 |
| 采用 Adoption | 开始使用 | 巩固信心、处理反馈 |
| 忠诚 Loyalty | 稳定使用 | 深度学术合作、口碑 |

## 渠道特性

| 渠道 | 类型 | 强项 | 适合 |
|---|---|---|---|
| 拜访 | 面对面 | 深度、互动、关系 | 学术深谈、决策支持、A 类客户 |
| 科室会/大会 | 面对面 | 群体、权威 | 学术传播、专家背书 |
| 邮件 | 数字 | 精准、可追踪 | 定向内容、跟进 |
| 平台/APP 内容 | 数字 | 随时、可复访 | 教育材料、循证库 |
| 直播/webinar | 数字 | 规模、专家 | 学术会议、新数据发布 |
| 推送/提醒 | 数字 | 高频、轻量 | 提醒、大众触达、C 类客户 |

## 内容-渠道匹配矩阵

| 内容类型 | 优先渠道 |
|---|---|
| 深度学术/临床决策 | 面对面（拜访/科室会） |
| 循证更新/新数据 | 面对面 + 直播 + 邮件 |
| 教育/背景材料 | 平台内容 + 邮件 |
| 提醒/轻触达 | 推送 + 邮件 |

## 分层 × 渠道（衔接 customer-segmentation）

- **A 类客户**：面对面为主 + 数字补充，高频深度。
- **B 类客户**：面对面 + 数字并重，中频。
- **C 类客户**：数字为主，低频轻量。

## 节奏原则

- **不过密**：避免短期内对同一客户触点堆叠（骚扰感）。
- **不遗忘**：高优先客户不长时间无触点。
- **联动**：数字为面对面预热与跟进（会前推送、会后邮件）。
- **一致**：跨渠道核心信息一致，不自相矛盾。

## 合规

- **对外内容一律经 MLR**（promo-material-mlr），本技能不豁免内容合规。
- 数字互动遵守客户 consent 与数据隐私；PII 不入非授权系统。
- 互动记录合规登记，不与推广不当挂钩。
