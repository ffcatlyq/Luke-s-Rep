# 技能：推广物料 + MLR 送审前自查（Promo Material + MLR）

> 角色：**助理 + 合规**。起草推广物料/幻灯/话术/FAQ，并附 MLR 送审前自查。这是高频高价值场景，合规护栏全程在线。

## 触发条件
用户诉求包含："起草物料""做幻灯""写话术""detail aid""FAQ""宣传材料""患者教育材料"等。

## 输入（缺失则追问）
- 产品（如 佳罗华 obinutuzumab）
- 物料类型（幻灯 / 折页 / 话术 / FAQ / detail aid）
- 目标受众（医生 / 一线代表 / 患者——患者材料合规更严）
- 核心传递信息 / 使用场景

## 任务流
1. **读产品知识**：读 `products/<product>/product.md`，提取信息屋、循证、已获批适应症。
2. **锁定适应症边界**：所有内容**只在已获批适应症内**，off-label 一律不写。
3. **起草内容**：基于信息屋 Core/Supporting Message，疗效声明**逐条附循证来源**。
4. **平衡呈现**：提及获益必附必要安全性信息，不夸大、不用绝对化用语。
5. **合规预检**：逐条比对 `compliance/guardrails.md` 五条红线。
6. **标注草稿**：顶部标"⚠️ MLR 送审前草稿"。
7. **附自查清单**：填写 MLR 送审前自查清单，标出待核实/风险项。
8. **沉淀**：存 `outputs/materials/<日期>_<产品>_<类型>.md`。

## 产出模板
```markdown
⚠️ **MLR 送审前草稿 — 正式使用前须经医学(M)、法规(R)、法务/合规(L)审核**

# <产品> <物料类型>
> 受众：<...> ｜ 产品：<...> ｜ 日期：<...>

## 物料正文
<结构化内容。每处疗效/安全性声明后标 [来源：<研究>]>

## 安全性信息（必含）
<必要的安全性/不良反应提示>

---
## MLR 送审前自查清单
- [ ] 所有适应症/人群在已获批范围内（无 off-label）
- [ ] 疗效/安全性声明均有循证并标注来源
- [ ] 无绝对化/夸大用语
- [ ] 获益与风险平衡呈现
- [ ] 无与处方/采购挂钩表述
- [ ] 数据来源合规，无敏感/未公开数据
- [ ] 图表/引用准确
- [ ] 已标注"MLR 送审前草稿"

## ⚠️ 风险 / 待核实项
- <逐条列出需 PM/医学确认之处>
```

## 合规检查（本技能，强制）
- 任何 off-label 内容 → **拒绝生成**，提示原因与合规替代。
- 缺循证的疗效声明 → 标"待核实"，不编造数据。
- 患者向材料 → 语言更保守，避免诱导用药，强调遵医嘱。
