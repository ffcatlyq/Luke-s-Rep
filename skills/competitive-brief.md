# 技能：竞品 / 市场简报（Competitive Brief）

> 角色：**参谋**。为某产品或某组合生成结构化竞争洞察简报，支持策略共创与决策。

## 触发条件
用户诉求包含："竞品简报""竞争格局""市场分析""对比某竞品""X 怎么打"等。

## 输入（缺失则追问）
- 目标产品（如 高罗华 glofitamab）或组合（如 CD20 franchise）
- 分析目的（内部策略输入 / 汇报 / 销售赋能）
- 关注维度（可选：疗效、安全性、可及性、给药、价格等）

## 任务流
1. **定位知识**：读取目标产品 `product.md`；若为组合，读 `franchise.md` + 相关产品。
2. **读疾病格局**：读 `landscape.md` 获取市场与竞争环境。
3. **提取竞争维度**：从 `product.md` 的"竞争格局""异议应对"提取，必要时补充 `landscape.md` 竞争信息。
4. **结构化对比**：按维度做我方 vs 竞品对比矩阵。
5. **形成洞察与建议**：给出差异化机会、风险、可行动建议（参谋视角，但不替定顶层策略）。
6. **合规校验**：竞品比较须客观、基于循证、**不得贬损**；缺数据标"待核实"。
7. **沉淀**：存 `outputs/briefs/<日期>_<产品>_竞品简报.md`。

## 合规检查（本技能）
- [ ] 竞品比较基于公开/循证数据，客观不贬损
- [ ] 无 off-label 延伸
- [ ] 缺失数据标注"待核实"，未编造
- [ ] 若用于对外，转交"物料+MLR"技能补充送审标注
