# 技能：文档协作撰写（Doc Co-Authoring）

> 角色：**助理 + 参谋**。引导用户结构化地共创文档——方案（proposal）、策略文档、决策文档、PRD、技术/流程 spec。核心是三阶段工作流：先高效传递上下文，再分节迭代精修，最后用"新读者视角"验证文档对他人可读。
> 移植自通用技能库（silicon-hitchhiker），已适配 PM 场景。适合品牌计划、上市方案、跨部门决策文档等重头产出。

## 触发条件
用户诉求包含："写文档""起草方案""写个 proposal""做份决策文档""写 PRD/spec""把这个写成文档"，或明显要开始一个有分量的写作任务。

## 何时用这个工作流
文档有多个 stakeholder、需要说服/决策、或以后要给别人读（尤其别人会丢给 AI 帮读）时，走这个三阶段流程。简单短文直接写即可，不必启用。**开工前先问用户**：要走这个结构化流程，还是自由写。

## 阶段 1：上下文收集
**目标**：把"用户知道的"和"智能体知道的"之间的差距补齐。

1. **先问元信息**（5 问）：
   - 这是什么类型文档？（决策文档/方案/spec…）
   - 主要受众是谁？
   - 读完希望达到什么效果？
   - 有模板或指定格式吗？
   - 其他约束或背景？
2. **让用户信息倾倒**：背景、相关讨论、为什么不用替代方案、组织背景（团队动态/历史/政治）、时间压力、依赖、stakeholder 顾虑。告诉用户不用organize，先全倒出来。
3. **提澄清问题**：基于 gap 生成 5-10 个编号问题，用户可用速记回答（"1: yes, 2: 见某文档, 3: no 因为向后兼容"）。
4. **退出条件**：能就边界情况和取舍提问而不需要再解释基础概念时，上下文就够了。

## 阶段 2：分节精修
**目标**：逐节共创——澄清 → 头脑风暴 → 取舍 → 起草 → 精修。

1. **定结构**：结构清晰就问从哪节开始；不清晰就按文档类型建议 3-5 节。**从未知最多的节开始**（决策文档通常是核心提案，spec 通常是技术方案），摘要节留到最后。
2. **建骨架**：创建带占位符的文档文件（各节标题 + "[待写]"）。
3. **每节循环**：
   - **澄清**：问 5-10 个该节要点问题
   - **头脑风暴**：列 5-20 个可能纳入的点（找用户忘了提的、没想到的角度）
   - **取舍**：让用户指出留/删/合并（"留 1,4,7；删 3 重复 1；合并 11+12"）
   - **补缺**：问还有什么重要的漏了
   - **起草**：用选中的点替换该节占位符
   - **精修**：用户给反馈 → 做外科手术式编辑（`str_replace`，不重印全文）。**建议用户不要直接改文档，而是说明要改什么**——这样智能体学到风格，后续节更准。
4. **临近完成**（80%+ 节完成）：通读全文，检查流畅性、一致性、冗余/矛盾、"注水"感——每句是否都有分量。

## 阶段 3：读者测试
**目标**：用无上下文的"新读者视角"验证文档对他人可读，抓作者盲点。

1. **预测读者问题**：生成 5-10 个读者realistically 会问的问题。
2. **测试**：
   - 有子智能体（sub-agent）能力时——用干净上下文的子智能体，只给文档 + 问题，看回答对不对。
   - 无子智能体时——引导用户开新会话粘贴文档提问。
3. **额外检查**：文档哪里对读者可能有歧义？假设读者已知哪些背景？有无内部矛盾？
4. **修补**：新读者答错/卡住的地方，回到阶段 2 精修相关节。
5. **退出条件**：新读者能稳定答对、不再冒出新 gap，文档就 ready。

## 最终审查
1. 建议用户自己通读一遍——文档归他所有，质量他负责。
2. 核对事实、链接、技术/数据细节。
3. 确认达到预期效果。

## PM 场景适配
- **挂知识包**：涉及产品的文档，先读 `knowledge-packs/<领域>/` 对应 `product.md`/`franchise.md`，事实以知识包为准。
- **挂 KPI**：方案/计划类文档尽量对齐 PM 考核维度。
- **沉淀**：成稿存 `outputs/docs/<日期>_<主题>_<类型>.md`。

## 合规检查（本技能）
- [ ] 产品疗效/数据表述有循证、不夸大、不 off-label（以知识包为准）
- [ ] 面向外部的文档标注"⚠️ MLR 送审前草稿"并走 `promo-material-mlr.md` 自查
- [ ] 敏感/未公开数据标注分级，C3/C4 不进外发版本
- [ ] 事实、链接、数据在最终审查阶段已核对
