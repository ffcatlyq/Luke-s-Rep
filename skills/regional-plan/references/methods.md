# 区域计划方法论

## 本地化框架：不可变 vs 可调整

中央策略哪些照搬、哪些本地化：

| 维度 | 处理 | 说明 |
|---|---|---|
| 品牌定位 | 不可变 | 全国一致 |
| 核心信息（core messages） | 不可变 | 循证、合规，不改口径 |
| 合规边界 | 不可变 | 适应症、off-label 红线 |
| 目标 | 下沉调整 | 按区域潜力分解 |
| 执行方式/战术组合 | 可本地化 | 结合区域格局选打法 |
| 渠道组合 | 可本地化 | 接 omnichannel-engagement |
| 节奏/时间线 | 可本地化 | 按区域实际排期 |
| 资源分配 | 可本地化 | 接 territory-management |

原则：**信息与合规不走样，执行按区域优化**。

## 区域计划结构

一份区域执行计划应含：

1. **区域目标**：本区域要达成什么（数字+定性）。
2. **区域洞察**：本区格局、客户、竞争的关键判断（读 `regions/china-market.md`）。
3. **策略落地**：中央策略在本区如何体现（本地化后的打法）。
4. **客户覆盖计划**：分层 + 覆盖标准（接 customer-segmentation）。
5. **关键行动与时间线**：里程碑、活动、节奏。
6. **资源与团队**：辖区、产能、预算（接 territory-management）。
7. **风险与依赖**：需中央支持的、外部风险。
8. **衡量方式**：怎么知道落地成功。

## 与其他技能衔接

- 目标分解 → `performance-review` / `territory-management`
- 客户分层与覆盖 → `customer-segmentation`
- 渠道编排 → `omnichannel-engagement`
- 活动执行 → `regional-event`
- 反馈上传/资源申请 → `central-regional-align`

## 合规

- 客户/销售数据敏感，不外传、不进 git。
- 推广内容走 MLR，活动走合规留痕。
- 资源分配留痕，不与处方量挂钩。
