# 辖区管理方法论

## 辖区划分四原则

划分辖区时平衡四点，通常需权衡取舍：

| 原则 | 含义 | 为什么 |
|---|---|---|
| **地理集中** | 同城/同片区尽量归一个辖区 | 减少路途、提高拜访效率 |
| **工作量均衡** | 各辖区加权工作量可比 | 公平，避免旱涝不均 |
| **潜力均衡** | 各辖区潜力总量可比 | 机会公平，目标可达 |
| **关系延续** | 尽量保留既有客户关系 | 减少切换成本、保护关系资产 |

四原则常冲突（地理集中可能导致潜力不均），按团队实际排序权衡，记录取舍理由。

## 加权工作量

不同分级医院的覆盖投入不同，工作量按分级加权而非只数医院数：

```
辖区工作量 = Σ(医院数_分级 × 权重_分级)
```

权重按覆盖频次比例设定（示例，实际按团队标准）：C30 : T70 : T300 ≈ 3 : 2 : 1。

## 覆盖频次标准（示例占位）

按分级设最低拜访频次，向核心医院倾斜：

| 分级 | 建议覆盖频次（占位） | 深度 |
|---|---|---|
| C30 | 高频 | 深度学术+关系，管理者可亲自参与 |
| T70 | 中频 | 常规学术覆盖 |
| T300 | 低频/机会型 | 长尾维护 |

> ⚠️ 具体频次数字为占位，须替换为罗氏内部辖区覆盖标准。

## 目标分解方法

区域目标下沉到辖区的两种基准：

- **按潜力**：辖区目标 ∝ 辖区潜力占比。适合成熟市场、潜力数据可靠时。
- **按历史基数**：辖区目标 = 基数 × 统一或差异化增长率。适合潜力数据不足时。
- **加权**：潜力与基数按比例混合，平滑两者偏差。

分解后必查**增长率合理性**：某辖区增长要求是否显著偏高/偏低，手动微调并记录理由，避免机械分解导致目标不可达。

## 合规

- 目标分解与资源分配规则透明、留痕。
- 辖区/目标/名单数据敏感，不外传、不进 git。
- 资源向高分级倾斜是效率考量，不得转化为与处方量挂钩的不当激励。
