# 区域活动方法论

## 活动类型

| 类型 | 规模 | 场景 | 合规重点 |
|---|---|---|---|
| 科室会 | 小 | 单科室学术交流 | 内容循证、留痕 |
| 区域学术会 | 中 | 多医院/区域专家 | 讲者 FMV、内容 MLR、费用 |
| 卫星会 | 中大 | 依托大会 | 主办方规则 + 内部合规双重 |
| 线上会/webinar | 灵活 | 数字触达 | 内容 MLR、consent |

## 合规留痕清单

区域活动必须留档的环节（备查）：

- [ ] **立项审批**：活动申请与审批记录
- [ ] **讲者**：遴选依据（学术资质）、合同、FMV 劳务标准、利益冲突申报（走 speaker-management）
- [ ] **内容**：讲者材料 MLR 送审记录（走 promo-material-mlr）
- [ ] **费用**：预算审批、费用凭证，合规范围内
- [ ] **签到**：参会签到表（PII，内部留存）
- [ ] **执行**：议程执行记录

> 任何环节不得与参会者/客户的处方、采购量挂钩。

## 效果评估维度

| 维度 | 看什么 |
|---|---|
| 参会 | 目标 vs 实际到会、目标客户覆盖 |
| 互动 | 提问/讨论质量、专家参与度 |
| 目标达成 | 学术信息传递、关系推进 |
| 洞察 | 收集到的客户反馈/竞品信息（→ field-insight-synthesis） |
| ROI | 投入 vs 产出（定性+定量） |

## 与其他技能衔接

- 讲者遴选与管理 → `speaker-management`
- 讲者材料/物料合规 → `promo-material-mlr`
- 会后洞察回流 → `field-insight-synthesis`
- 大型活动纳入区域计划 → `regional-plan`

## 合规

- 讲者、内容、费用全程合规留痕，不与处方采购挂钩。
- 材料标 `⚠️ MLR 送审前草稿`。
- 参会/费用/签到 PII 数据敏感，不外传、不进 git。
