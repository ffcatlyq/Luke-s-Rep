# 一线洞察方法论

## 信号 vs 噪音

不是所有反馈都值得上报。区分：

| | 信号（值得关注） | 噪音（个案/情绪） |
|---|---|---|
| 频率 | 反复出现 | 一次性 |
| 广度 | 跨区/跨客户一致 | 单点孤例 |
| 影响 | 对策略/执行有实质影响 | 影响有限 |
| 性质 | 事实/趋势 | 情绪/抱怨 |

噪音不丢弃（可能是早期信号），但标注、不放大。信号才进入提炼与回流。

## so-what 提炼框架

从"发生了什么"到"意味着什么、该做什么"，逐层追问：

```
What（观察）    → 一线看到/听到什么（事实）
So-what（洞察）  → 这意味着什么？为什么重要？
Now-what（行动） → 我们该做什么？谁做？
```

原样转发反馈 = 没做提炼。价值在 so-what 与 now-what。

## 提炼质量自查

- 是**趋势**还是**个案**？（个案别包装成趋势）
- 有**证据**支撑吗？（几个区/几个客户，非"我觉得"）
- so-what 是否**具体**？（"客户关心安全性"太泛，"C30 医院对 XX 不良反应管理反复提问"才可行动）
- 行动建议是否**可执行、有归属**？

## 双向回流机制

打通区域-中央：

- **上行**：区域一线洞察 → 提炼 → 回流中央（物料/竞品/策略）。
- **下行**：中央策略/物料 → 下沉区域（接 central-regional-align，后续批次）。
- **闭环**：中央根据洞察调整后，反馈调整结果给区域，形成闭环而非单向上报。

## 合规

- 回流聚焦趋势与洞察，**脱敏个案**，客户 PII 不外传。
- 竞品信息只用合法公开来源/合规渠道，剔除来路不明或涉密内容。
- 洞察不含 off-label 或未证实疗效声明；产品声明回流走 MLR。
