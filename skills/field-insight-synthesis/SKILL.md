# 一线反馈闭环（Field Insight Synthesis）

把一线散落的见闻——客户异议、竞品动作、市场信号——提炼成中央市场用得上的结构化洞察。

## 何时用 / 人群

| 人群 | 是否主用 | 视角 |
|---|---|---|
| 区域市场（pst） | ✅ 主用 | 汇总区域一线反馈 → 提炼 → 上传中央 |
| 销售管理（sales-mgmt） | ✅ 主用 | 汇总团队一线见闻 → 洞察 → 回流 |
| 中央市场（central-marketing） | ✅ 主用（接收端） | 消化区域洞察 → 反哺策略/物料/竞品 |

## 核心：从碎片到洞察到行动

```
原始反馈（碎片）→ 分类聚合 → 提炼洞察（so-what）→ 行动建议 → 回流中央
```

不是把反馈原样转发，而是**提炼出"这意味着什么、该做什么"**。区分**信号**（值得关注的趋势）与**噪音**（个案/情绪）。

## 反馈类型

| 类型 | 例子 | 常回流到 |
|---|---|---|
| 客户异议/关切 | 反复出现的疗效/安全/可及性疑问 | 物料、话术、FAQ |
| 竞品动态 | 竞品新数据、新策略、地面动作 | 竞品简报（competitive-brief） |
| 市场信号 | 准入变化、诊疗趋势、患者流 | 策略、市场规划 |
| 执行反馈 | 物料好不好用、活动效果 | 中央市场物料/活动优化 |

## 工作流骨架

| 场景 | 触发说法 | 一句话 |
|---|---|---|
| 1. 反馈汇总提炼 | "把这些反馈整理成洞察""一线声音汇总" | 收集 → 分类 → 提炼 so-what → 行动建议 |
| 2. 竞品动态汇总 | "汇总竞品地面动作" | 归集竞品信号 → 交 competitive-brief 深化 |
| 3. 回流中央 brief | "整理给中央市场""洞察回流" | 结构化 brief（可双语）→ 明确接收方与建议 |

方法论（信号vs噪音、提炼框架、回流机制）见 `references/methods.md`；模板见 `templates/`。
竞品部分接 `competitive-brief`；对上/跨区回流可用 `bilingual-report`。

## 合规注意

- 一线反馈中的客户具体言论/名单属敏感——回流时**聚焦趋势与洞察，脱敏个案**，不外传客户 PII。
- 竞品信息只用**合法公开来源与合规渠道获取**的内容，不采信/不传播来路不明或涉密信息。
- 洞察不得包含 off-label 或未经证实的疗效声明；涉及产品声明的回流须走 MLR。
