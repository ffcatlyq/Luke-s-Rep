# 合规要求与角色职责

## 项目合规要求

所有项目必须遵守（详见 `compliance/guardrails.md`）：
- 对外/推广材料须经 MLR 审核，正式使用前标 `⚠️ MLR 送审前草稿`
- 讲者遴选基于学术资质、劳务符合 FMV，不与处方/采购量挂钩
- 涉及 HCP 互动的活动符合反商业贿赂法规，全程留痕
- 项目预算须经审批，费用凭证归档
- 客户/名单/预算等敏感数据不外传、不写入可外发产出、不进 git

## 三类人群在项目管理中的职责

| 人群 | 典型项目职责 |
|------|------------|
| **中央市场（PM）** | 全国大型学术会/AdBoard 策划、产品上市准备整体管理、患者项目设计 |
| **区域市场（PST）** | 区域上市落地、大型区域会/多城市巡讲执行、区域专项 |
| **销售管理** | 团队级专项攻坚、区域启动会、辖区落地项目 |

> 项目负责人（Accountable）对项目最终结果负责；跨部门项目须明确各职能的 RACI。
> 大型活动的现场执行细节走 `regional-event`；本技能负责项目整体的拆解、分工与管控。
