## RACI矩阵

| 任务 | PM | 角色2 | 角色3 | 角色4 |
|------|:--:|:-----:|:-----:|:-----:|
| | A/R | | | I |
| | A | R | C | I |

## 原则

- 每项任务有且仅有一个 **A**（Accountable）
- **R** 可以有多个，但应明确主要执行者
- **A** 对任务最终结果负责，即使不亲自执行
- **C** 在执行前需被咨询意见
- **I** 在执行后需被告知结果
