# 项目管理常用邮件模板

## 1. 项目启动通知

**场景**：项目正式立项后，通知所有stakeholder

```
Subject: [项目名称] — 项目启动通知

各位同事，

[项目名称]已正式立项，现将项目基本信息通知如下：

■ 项目目标：[简述]
■ 项目时间：[起止日期]
■ 项目负责人：[姓名]
■ 关键里程碑：[列出2-3个]

各位在项目中的角色和职责请参考附件RACI矩阵。
如有疑问，请随时联系我。

[签名]
```

## 2. 进度更新

**场景**：定期向stakeholder汇报项目进度

```
Subject: [项目名称] — 进度更新（第X周）

各位同事，

以下是[项目名称]本周进度更新：

■ 当前Phase：[Phase名称]
■ 整体状态：🟢正常 / 🟡需关注 / 🔴有风险

【本周完成】
- ✅ [任务1]
- ✅ [任务2]

【进行中】
- 🔄 [任务3] — 预计[日期]完成

【需要支持】
- [具体事项] — 需要[谁]在[日期]前[做什么]

【下周计划】
- [任务4]
- [任务5]

[签名]
```

## 3. 风险预警

**场景**：识别到重大风险，需要升级或协调

```
Subject: [项目名称] — ⚠️ 风险预警：[风险简述]

[收件人]，

在[项目名称]执行过程中，识别到以下风险需要您的关注：

■ 风险描述：[具体描述]
■ 影响范围：[对项目的影响]
■ 当前状态：[已触发/即将触发]
■ 建议措施：[缓解方案]
■ 需要您的支持：[具体请求]
■ 决策截止日：[日期]

如需进一步讨论，我可以安排[时间]的简短会议。

[签名]
```

## 4. 邀请确认

**场景**：邀请讲者/参会者并确认

```
Subject: 学术交流邀请 — [会议名称]（[日期]，[城市]）

[尊称]，

诚挚邀请您参加[会议名称]：

■ 时间：[日期] [时间]
■ 地点：[地点]
■ 主题：[会议主题]
■ 您的角色：[讲者/主持/讨论嘉宾]

[如为讲者]
■ 演讲题目：[题目]
■ 演讲时长：[时长]
■ 幻灯截止日：[日期]

请于[日期]前回复确认是否出席。
如有任何问题，请随时联系我。

[签名]
```

## 5. 会后感谢

**场景**：会议结束后向讲者和参会者致谢

```
Subject: 感谢参加[会议名称]

[尊称]，

感谢您在[日期]参加[会议名称]。
您的[演讲/分享/参与]为与会者带来了宝贵的学术交流机会。

[如有后续]
会议纪要将于[日期]发送给您。
如有任何后续问题，欢迎随时联系。

[签名]
```

## 6. 项目收尾通知

**场景**：项目完成后的总结通知

```
Subject: [项目名称] — 项目收尾总结

各位同事，

[项目名称]已顺利完成，感谢各位的支持和协作。

■ 项目成果：[简述]
■ 关键数据：[参会人数/覆盖城市/等]
■ 经验教训：[1-2条]
■ 后续行动：[如有]

详细复盘报告请参考附件。

[签名]
```
