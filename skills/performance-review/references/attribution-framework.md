# 达成归因框架

## 量价结构分解

销售差距的第一层拆解——差距来自哪里：

```
销售额 = 量 × 价 × 产品结构
```

- **量**：客户覆盖数 × 单客户产出。量的差距→看覆盖与渗透。
- **价**：单价变化（医保准入、招标价、折扣）。多为外部/准入因素。
- **结构**：高值 vs 低值产品的组合变化。

先定位差距主要落在哪一维，再深挖。

## 覆盖漏斗

量的差距沿漏斗逐层查，哪一环掉了：

```
目标医院  →  已覆盖  →  已准入(进药)  →  有处方  →  处方量达标
```

每一环算转化率，与标杆/上期比，找断点。医院分级（C30/T70/T300）分别看——核心医院断点影响最大。

## 5 类归因

差距原因归为 5 类，标注可控性：

| 类别 | 例子 | 可控性 |
|---|---|---|
| 市场/竞争（外部） | 竞品新数据、市场萎缩、政策 | 低（不可控） |
| 覆盖执行 | 拜访频次不足、目标医院漏覆盖 | 高 |
| 团队能力 | 学术传递弱、异议处理差 | 高（→ field-coaching） |
| 资源投入 | 活动/费用配置不当 | 中（→ territory-management） |
| 产品/准入 | 未进医保、适应症限制 | 中（跨部门） |

**归因原则**：
- 区分**可控 vs 不可控**——行动只针对可控项。
- 避免单一归因，通常多因叠加。
- 用数据支撑归因，不凭感觉。
- 归因到团队能力时，导向 `field-coaching`；归因到资源/辖区时，导向 `territory-management`。
