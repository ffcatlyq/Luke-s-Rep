# 提取、预警与质量检查

## 1. 获取源数据

1. 打开 Receiver List，确认用户已登录且页面数据加载完成。
2. 使用原生导出建立基础字段清单，并记录导出行数。
3. 检查原生导出是否含所有所需额度字段。缺失时，在同一已登录页面的只读列表请求中获取全量记录；分页读取需逐页累计并保留唯一 `DoneeID`。
4. 在全量读取后检查：
   - 记录总数与页面显示总数一致；
   - `DoneeID` 非空率和重复数；
   - 随机抽样 2–3 条，受赠方名称、失效日期、一个额度字段与页面一致。

若页面不可访问、未登录或无权限，只报告阻碍并请用户完成登录/授权；不要尝试绕过认证。

## 2. 预警计算

- 数据截至日：以实际读取/导出当天为准，并在 Excel `汇总` 中写明。
- `距到期天数 = 尽职调查有效期至 - 数据截至日`（按日历日）。
- 预警层级：

| 条件 | 到期预警 | 建议样式 |
|---|---|---|
| 有效期缺失或无法解析 | 待补充 | 浅黄 |
| `< 0` | 已到期 | 浅红 |
| `0–30` | 30天内到期 | 橙/浅红 |
| `31–90` | 31–90天到期 | 浅黄 |
| `> 90` | 正常 | 无强调 |

不要用系统“失效标记”替代日期计算；将两者并列以便核对。

## 3. Excel 质量标准

1. `汇总`：展示总数及每类预警数量；总数应等于明细数据行数。
2. `受赠方明细`：冻结第一行、启用自动筛选；日期采用 `yyyy-mm-dd`，金额和比例采用合理数字格式；预警行或单元格清晰着色。
3. `字段说明`：提供字段映射、数据截至日、源为 GSD Receiver List，以及内部敏感信息标识。
4. 验证生成后的文件：打开工作簿，核对工作表名、明细行数、列名、筛选范围和至少一条预警记录的样式。
5. 输出只存本地受控路径。含明细的临时下载/中间数据在交付验证完成后清理；不要删除用户原始文件。

## 4. 交付话术

只向用户说明：文件位置、数据截至日、明细记录数及预警汇总。不要在聊天正文粘贴名单、额度或审计发现。
