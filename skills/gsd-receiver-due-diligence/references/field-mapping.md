# GSD 受赠方字段映射

以下是 Receiver List 已验证的字段口径。GSD 页面/后台版本可能变化；每次导出前以页面列名、字段详情弹窗或原生导出为准。

| Excel 显示字段 | GSD 字段/来源 | 说明与使用边界 |
|---|---|---|
| 受赠方 | `DoneeName` / 原生导出“受增方” | 工作簿中统一显示为“受赠方”。 |
| 部门 | `Department` | 保留系统值。 |
| 级别 | `Level` | 保留系统值。 |
| 受赠方状态 | `DoneeStatus` | 与尽调结果分列，不可混用。 |
| 尽职调查结果 | `DueDiligenceResult` | 原生导出可能显示为“结果”。 |
| 尽职调查有效期至 | `ExpirationDate` | 原生导出可能显示为“失效日期”。这是到期预警的唯一日期来源。 |
| 系统失效标记 | `Expired` 或页面等效字段 | 与“距到期天数”同时保留，避免因系统时区/状态规则差异而覆盖原始事实。 |
| 限制额度 | `CappingLimit` | GSD 详情弹窗显示标签为“限制额度”。 |
| 提升后总额度 | `DDAmount` | GSD 详情弹窗显示标签为“提升后总额度”。 |
| 当前可用额度 | `DoneeCappingAmount` | GSD 详情弹窗显示标签为“当前可用额度”；不要未核实地改称“剩余额度”。 |
| 已使用额度 | `UsedAmount` | 保留系统值。 |
| 提升后总额度占比 | `DDAmountPercentage` | 保留系统值及其百分比格式。 |
| 已使用额度占比 | `UsedPercentage` | 保留系统值及其百分比格式。 |
| 总额度可提升至 | `IncreaseCappingTo` | GSD 详情弹窗显示标签为“总额度可提升至”。 |
| 审计发现 | `AuditFinding` 或页面等效字段 | 若源列表无此字段，留空并在字段说明中标注“源数据未提供”。 |
| GSD 受赠方 ID | `DoneeID` | 用于去重和回溯；不以名称作为唯一键。 |

## 不可替代的核对

- 原生导出通常覆盖受赠方、部门、级别、结果、状态、失效日期，但**可能不含额度字段**；不要因导出成功就假定字段完整。
- 额度字段使用页面数据时，应先拿一个样本和页面详情弹窗对照字段/标签，再开始全量拉取。
- 不以“额度字段之间的算术关系”改写字段名称或含义；GSD 的业务规则由系统决定。
