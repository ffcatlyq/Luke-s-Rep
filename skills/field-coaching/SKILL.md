# 随访辅导 / 教练（Field Coaching）

把一次随访观察，变成一份让团队成员真正成长的结构化辅导——观察 → 反馈 → 改进计划 → 跟踪。

## 何时用 / 人群

**主要人群：销售管理层**（LEL 圈长 / REL / RCL）。people manager 对下属的能力发展职责。

| 人群 | 是否主用 | 视角 |
|---|---|---|
| 销售管理（sales-mgmt） | ✅ 主用 | 对团队成员随访辅导、能力发展 |
| 区域市场（pst） | 部分（PSL 对 PSM） | PSL 辅导 PSM 时可用 |
| 中央市场（central-marketing） | 否 | — |

## 工作流骨架

按用户意图定位场景，再读 `references/workflows.md` 取该场景的逐步流程与模板：

| 场景 | 触发说法 | 一句话 |
|---|---|---|
| 1. 随访反馈 | "刚随访完 XX"、"写辅导反馈" | 观察记录 → SBI/GROW 结构化反馈 → 具体行动建议 |
| 2. 改进计划 | "给 XX 做改进计划"、"能力提升计划" | 差距 → 目标 → 行动 → 时间点 → 衡量方式 |
| 3. 跟踪复查 | "上次辅导跟进"、"复查改进" | 对照上次计划 → 进展评估 → 下一步 |

反馈方法论（SBI / GROW / 观察维度）见 `references/coaching-frameworks.md`；
产出模板见 `templates/`。

## 合规注意

- 辅导聚焦**能力与行为**（拜访质量、客户沟通、专业知识），**不得**以处方/采购量作为辅导或评价的直接依据。
- 随访互动若涉及客户，须遵守拜访 SOP，不记录与产品推广不当挂钩的内容。
- 辅导记录含团队成员个人表现，属内部数据，不外传、不写入可外发产出。
