# Field Coaching — 场景工作流

## 场景 1：随访反馈

**输入**：随访对象（团队成员）、随访场景（拜访了哪些客户/科室）、观察到的行为。

**步骤**：
1. **确认观察事实**：让用户提供具体观察（说了什么、做了什么、客户反应），不足则追问。区分"事实"与"评价"。
2. **按 SBI 结构化**（见 `coaching-frameworks.md`）：Situation（情境）→ Behavior（行为）→ Impact（影响）。每条反馈既覆盖做得好的，也覆盖待改进的。
3. **给具体行动建议**：针对待改进项，给可操作的下一步（"下次拜访前先……"），不空泛。
4. **邀请对方视角**：留出让团队成员自评的问题（GROW 的 Reality/Will）。

**产出**：一份随访反馈（见 `templates/coaching-feedback.md`）——观察事实 / 优势 / 待改进 / 行动建议 / 双方约定。

## 场景 2：改进计划

**输入**：能力差距（来自随访反馈或业绩数据）、时间范围。

**步骤**：
1. **锁定 2-3 个优先差距**：不贪多，聚焦影响最大的。
2. **每项差距设**：目标（具体可衡量）→ 行动（怎么做）→ 支持（管理者提供什么）→ 时间点 → 衡量方式。
3. **区分能力问题 vs 意愿问题**：路径不同（能力→培训/带教；意愿→动机对话）。
4. **约定复查节点**。

**产出**：改进计划表（见 `templates/improvement-plan.md`）。

> ⚠️ 若涉及正式绩效改进流程（PIP），走 `one-on-one-coaching` 技能的绩效面谈路径并挂 HR 合规，本技能只做能力发展性质的改进计划。

## 场景 3：跟踪复查

**输入**：上次的改进计划。

**步骤**：
1. 逐条对照上次计划的目标与时间点。
2. 评估进展（达成/部分/未达成），记录证据。
3. 未达成项归因（能力/意愿/外部），调整行动。
4. 更新下一轮计划。

**产出**：更新后的改进计划 + 进展记录。
