# 辅导方法论

## SBI 反馈模型

给具体、不带评判的反馈：

- **S — Situation（情境）**：具体的时间地点场景。"今天在 XX 医院血液科拜访 Y 主任时……"
- **B — Behavior（行为）**：观察到的具体行为，不是评价。✅"你在客户提出异议后直接跳到下一张幻灯" ❌"你不会处理异议"
- **I — Impact（影响）**：该行为造成的结果。"客户的疑问没被回应，后半程互动明显减少"

正面与建设性反馈都用 SBI。先具体肯定优势，再谈待改进。

## GROW 教练对话模型

辅导对话（非单向反馈）的结构：

- **G — Goal（目标）**：这次拜访/这个季度你想达成什么？
- **R — Reality（现状）**：实际发生了什么？让对方先自评。
- **O — Options（选项）**：还可以怎么做？引导对方产出方案，而非直接给答案。
- **W — Will（意愿/行动）**：你决定下一步做什么？何时？

教练原则：**多问少讲**，让团队成员自己得出结论，管理者的答案不如他自己想出的答案有效。

## 随访观察维度

随访时按维度观察，避免只凭印象：

| 维度 | 观察点 |
|---|---|
| 拜访准备 | 目标是否清晰、资料是否到位、客户背景是否了解 |
| 开场与建立关系 | 是否快速切入、专业形象 |
| 需求探询 | 是否提问了解客户关注点，还是单向灌输 |
| 信息传递 | 是否准确、循证、合规（不 off-label、不夸大） |
| 异议处理 | 是否倾听、回应到位 |
| 缔结与跟进 | 是否有明确下一步 |

> 观察记录只记行为事实，评价放到反馈环节。合规维度（循证/不 off-label）任何时候不可让步。

## 能力 vs 意愿

辅导前先判断问题性质：

| | 意愿高 | 意愿低 |
|---|---|---|
| **能力高** | 授权、给挑战 | 激励、找动机（可能倦怠或不认同） |
| **能力低** | 带教、培训、示范 | 先解决意愿，再谈能力 |

用错路径无效——对意愿问题做技能培训、或对能力问题只谈动机，都白费。
