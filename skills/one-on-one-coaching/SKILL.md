# 常规 1:1 与发展对话（One-on-One Coaching）

把每周/每两周的 1:1，从"随便聊聊"变成有结构、推动成长、建立信任的定期对话。

## 何时用 / 人群

**主要人群：销售管理层**（LEL 圈长 / REL / RCL）等带人经理。

| 人群 | 是否主用 | 视角 |
|---|---|---|
| 销售管理（sales-mgmt） | ✅ 主用 | 对团队成员的定期 1:1、发展对话 |
| 区域市场（pst） | 部分（PSL 对 PSM） | 带人的区域市场负责人可用 |
| 中央市场（central-marketing） | 否 | — |

## 与 field-coaching 的分工

| | field-coaching | one-on-one-coaching（本技能）|
|---|---|---|
| 场景 | 随访后针对**具体拜访**的辅导 | 定期 1:1、**持续的**发展/目标对话 |
| 触发 | 一次 ride-along | 每周/双周固定 1:1 |
| 焦点 | 拜访技能与行为 | 全面发展、职业、目标、状态 |

> 随访后的具体反馈走 `field-coaching`；本技能是**贯穿的 1:1 节奏**，可引用 field-coaching 的观察作为素材。

## 1:1 不是什么

- ❌ 不是纯业绩追问会（那是 business-review / performance-review）
- ❌ 不是经理单向布置任务
- ✅ 是**成员为主角**的对话——听、问、支持、共同定下步

## 工作流骨架

| 场景 | 触发说法 | 一句话 |
|---|---|---|
| 1. 1:1 议程准备 | "准备明天的 1:1""1:1 议程" | 上次跟进 + 成员议题 + 经理议题 + 发展话题 |
| 2. 发展/职业对话 | "跟 XX 聊发展""职业对话" | 现状 → 期望 → gap → 发展行动（GROW 引导）|
| 3. 目标跟进复盘 | "跟进 XX 的目标""1:1 复盘" | 对照目标 → 进展/障碍 → 支持与下步 |

教练提问库、GROW/发展对话框架见 `references/methods.md`；模板见 `templates/`。
随访具体反馈接 `field-coaching`；纪要/action 走 `meeting-minutes`。

## 合规注意

- 1:1 聚焦**能力、行为、发展与状态**，不以处方/采购量作为评价或施压依据。
- 涉及成员个人信息（绩效、发展、健康/情绪）属敏感——严格保密，不外传、不进 git。
- 教练对话内容默认保密，建立信任前提。
