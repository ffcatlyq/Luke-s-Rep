# One-on-One Coaching — 场景工作流

## 场景 1：1:1 议程准备

**输入**：成员、上次 1:1 记录、近期发生的事。

**步骤**：
1. **回顾上次 action**：上次定的事进展如何。
2. **留出成员议题空间**：1:1 以成员为主角，先问"你想聊什么"。
3. **经理议题**：需要同步/反馈/对齐的事（简洁，不喧宾夺主）。
4. **发展话题**：定期插入成长/职业话题，不只谈眼前事务。

**产出**：1:1 议程（见 `templates/one-on-one-agenda.md`）。

## 场景 2：发展/职业对话

**输入**：成员当前状态、职业期望。

**步骤**（GROW 引导，见 `methods.md`）：
1. **Goal**：成员想去哪（能力/职业目标）。
2. **Reality**：现状如何，有哪些证据（可引用 field-coaching 观察）。
3. **Options**：达成目标有哪些路径。
4. **Will**：定下具体发展行动、时间、支持。

**产出**：发展对话记录/发展计划（见 `templates/development-conversation.md`）。

## 场景 3：目标跟进复盘

**输入**：成员的目标/发展计划。

**步骤**：
1. **对照目标看进展**：完成了什么、卡在哪。
2. **诊断障碍**：能力问题？资源问题？外部因素？
3. **提供支持**：经理能给什么支持（资源/辅导/关系）。
4. **定下步**：调整或推进，明确 action。

**产出**：目标跟进记录（见 `templates/goal-followup.md`）。

> 内容保密，聚焦发展与状态，不以处方采购施压。成员信息敏感，不外传、不进 git。
