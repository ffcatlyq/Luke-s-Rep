# 1:1 与发展对话方法论

## GROW 框架（发展对话核心）

| 步 | 问什么 | 目的 |
|---|---|---|
| **G**oal | 你想达成什么？成功什么样？ | 明确目标 |
| **R**eality | 现状如何？有哪些事实/证据？ | 认清现状 |
| **O**ptions | 有哪些可能的路径？ | 拓展选项 |
| **W**ill | 你决定做什么？何时？需要什么支持？ | 落地承诺 |

> 经理少给答案、多问问题——让成员自己想出路径，承诺才更强。

## 教练提问库

**开场/状态**
- 最近怎么样？工作之外还好吗？
- 这周你想重点聊什么？

**推动思考（少给答案）**
- 你觉得问题的根源在哪？
- 如果重来一次，你会怎么做？
- 有哪些你还没试过的办法？

**发展/职业**
- 你希望一年后自己有什么不同？
- 哪部分工作最让你有能量？哪部分消耗你？
- 你觉得自己现在最需要成长的是什么？

**支持**
- 我能帮你什么？
- 有什么阻碍是你需要我去搬开的？

## 1:1 节奏建议

| 频率 | 适用 |
|---|---|
| 每周 | 新成员、变动期、需要密切支持 |
| 双周 | 成熟稳定的团队成员 |

- 时长 30–45 分钟，固定时间，尽量不取消（取消传递"你不重要"）。
- 成员议题优先，经理议题其次，定期插发展话题。

## 常见坑

| 坑 | 对策 |
|---|---|
| 变成业绩追问会 | 业绩归 business-review；1:1 聚焦人与发展 |
| 经理单向说 | 多问少说，成员为主角 |
| 只谈眼前事务 | 定期插入发展/职业话题 |
| 记录不跟进 | 每次回顾上次 action |
| 经常取消 | 固定时间、优先级高 |

## 与其他技能衔接

- 随访后具体拜访反馈 → `field-coaching`（可作发展对话素材）
- 1:1 纪要/action → `meeting-minutes`
- 涉及正式绩效评估 → `performance-review`（不同场景）

## 合规

- 聚焦能力/行为/发展，不以处方采购施压或评价。
- 成员个人信息（绩效/发展/情绪）严格保密，不外传、不进 git。
